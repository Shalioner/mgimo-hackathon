# Маршрут по навыкам Стратега

Определи намерение из реплики и сохранённого состояния. Для существующего кейса сначала прочитай `state/progress.md`. Для возврата используй `.venv/bin/python tools/next.py projects/<case> --resume`. Если проект неоднозначен и статус его не проясняет, спроси, какой продолжить.

| Что просит руководитель | Первый маршрут |
|---|---|
| Новая продуктовая задача | Создай кейс через `ledger.py init projects/<slug> --title "<название>"`, затем [постановка задачи](../problem-framing/SKILL.md) до C1. |
| «Продолжи», «где остановились» | [Сопровождение решения](../decision-support/SKILL.md) для восстановления состояния. Если предстоит работа, открой только навык текущего шага из [рабочего процесса](../../workflows/strategy.md). |
| «Почему выбрали этот вариант?» | `ledger.py trace projects/<case> DEC-NNN`. Ответь по сохранённым основаниям со ссылками на источники. |
| Новый материал после выбора | [Пересмотр решения](../../workflows/update-decision.md). Прими источник через [source-intake](../source-intake/SKILL.md) и проверь затронутые выводы через [impact-analysis](../impact-analysis/SKILL.md), когда есть CHG. |
| Возражение по выводу или расчёту | [Самоаудит](../self-audit/SKILL.md). Найди исходное утверждение и локатор, прежде чем менять вывод. |
| Просит выполнить конкретный этап | Возьми только навык этого этапа из [рабочего процесса](../../workflows/strategy.md) и проверь его входы. |

Назови следующий шаг одной строкой. При простом вопросе о состоянии, основании или результате достаточно чтения. Прямые команды T0 выполняй сразу. Если нужен выбор модели и хост уже передал маршрут, используй его. В остальных случаях действуй по разделу об экономичности в [AGENTS.md](../../AGENTS.md). Этот навык выбирает процедуру, а D1 и [хуки Codex](../../docs/NATIVE_HOST_ROUTING.md) выбирают и передают параметры модели.

На открытом C1, C2 или C3 предъяви материалы и дождись решения человека. При расхождении файлов проверь, есть ли у решения действующий выбор в реестре. Если выбор поставлен под пересмотр, сначала уточни ожидаемое решение на C2 и сохрани прежнюю квитанцию C3 в истории.
