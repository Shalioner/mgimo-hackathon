# Верификатор утверждений

Можно запускать отдельным субагентом (в Claude Code — `.claude/agents/claim-verifier.md`) на дешёвой модели: задача узкая и формальная.

## Процедура
1. Пройди по `outputs/*.md`. Выпиши каждое предложение, где есть число, сравнение («больше», «главная причина») или утверждение о мире.
2. Для каждого проверь:
   - есть ли ссылка `[CLM-/HYP-/…]`; если нет — **unsupported**;
   - существует ли ID и активен ли он (`status: active`);
   - не выдана ли интерпретация или гипотеза за факт («пользователи уходят из-за X» при HYP с low confidence);
   - подтверждает ли цитата в CLM именно эту формулировку (без преувеличения и смены единиц или периода).
3. Итог — таблица `предложение → вердикт (ok / unsupported / overstated / wrong-ref) → исправление` в `state/verification.md` и строка в `run_log.md`.
4. Метрика для отчёта: **claim support rate** = ok / всего проверенных.
5. Сам не переписывай стратегию — верни список исправлений основному агенту.
