# Контракт входа «Решение сегодня»

Вызов: `python skills/alternatives/decision_evidence.py path/case.json [--json]`.
Только стандартная библиотека Python 3.9+. Нет сети, моделей, записей в реестр.

Для новой задачи скопируй структуру любого JSON из
`evals/score9/decision-evidence/`, заменив содержание полностью. Не копируй приоритеты
M27 как универсальные. Файлы примеров — сценарные постановки на реальных кейсах,
а не новые решения владельцев этих проектов.

Поля корня:

- `question`, `scope`: решение и точная область; не «все пользователи» по одному тарифу.
- `as_of`: дата воспроизведения, ISO; это не системное текущее время.
- `priority_basis`: согласованное правило брифа или явное допущение для C2.
- `conditions`: ID, `scope`, `question`, `type`: `documented_property` либо `own_outcome`.
  Каждое условие должно использоваться хотя бы в одном действии.
  Второй тип нельзя закрыть публичной документацией. Наблюдения собственного эффекта
  пока рассматриваются вручную в основном workflow, не в этой утилите.
- `options`: минимум три, включая `status_quo` и `kill`. `id`, `kind`, `priority`
  (целое, меньше лучше), `action` с границей действия, `objection`, `requires`
  (словарь ID условия → ожидаемое true/false). Пустые условия допускаются только
  для status_quo/kill. Равный приоритет сохраняет всех лидеров. Это порядок среди
  допустимых действий из исходного сравнения, а не новая балльная модель.
- `observations`: список, возможно пустой. Для каждого наблюдения: ID, `type: fact`, `access: open`, `primary: true`, HTTPS `url`,
  `snapshot` относительно JSON, SHA-256 UTF-8 снимка, точная короткая `quote`,
  `locator`, `limitations`, `observed_at` и `review_by`. Последняя дата — явное
  допущение срока перепроверки, не гарантия свежести источника.
  Для влияния на условие: `condition`, булево `value`, совпадающий `scope`,
  `mapping_reason`. Для фоновых фактов — `condition: null`.

Границы источника, смысл привязки и полноту необходимых условий проверяет агент.
Код не устанавливает первичность сайта и истинность пересказа по метке `primary`.
Предпочтения, прогнозы и предположения не записываются наблюдаемыми фактами.
Объекты примеров CLM-D* — локальный реестр испытаний. При переносе в настоящий проект
зарегистрируй SRC/CLM штатно и валидируй; не используй ID испытаний в боевом DEC.

Выход: допустимые, исключённые и условные действия; предложение для C2; что
меняется при удалении каждого факта; вопросы с двумя контрфактическими ветвями.
Если обе ветви дают тот же выбор, вопрос может разблокировать вариант, но не меняет
сегодняшнюю рекомендацию. Конфликтующие значения остаются неизвестными до разбора.
Код 0 — есть предложение; код 2 — нет оснований/некорректный вход. Ни один код не
подтверждает C2. Не подменяй сегодняшним исправлением макета коммерческий запуск.

В примерах snapshot — короткие извлечённые фрагменты первичных документов,
полученных 2026-11-19. `sources/capture-hashes.json` содержит хэши первоначальных
полных ответов, они не нужны для офлайн-воспроизведения. Извлечение PDF: pdftotext
-layout. Повторная загрузка может дать иной документ; проверяй область и дату снова.

Область кейса и конфликт источников печатаются в кратком выводе. При отсутствующих
наблюдениях возвращается структурированный разбор неизвестных, а не ошибка формата.
Безусловный status_quo может оставаться допустимым; не назначай ему искусственное
условие только ради нужного отказа. Для стратегического сохранения курса, как и для
закрытия, нужны самостоятельные основания. Контрфактические ответы по одному условию
не исчерпывают совместные развилки; leave-one-out не обнаруживает группы дублирующих фактов.
