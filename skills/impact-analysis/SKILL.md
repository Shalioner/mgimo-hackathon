# Анализ влияния новых сведений

Полный порядок действий — `workflows/update-decision.md`. Здесь главное.

1. Затронутое определяет **не модель, а граф**: `python tools/ledger.py impact projects/<case> CHG-NNN`. Не добавляй к списку объекты «на всякий случай» и не убирай из него — если не согласен, объясни почему в `run_log.md`.
2. Обновляй снизу вверх: CLM/HYP → ALT → DEC → PRM/EXP.
3. Покажи человеку **diff решения**: для каждого затронутого объекта — было / стало / почему. Для демонстрации удобна цепочка:
   ```
   НОВЫЙ ИСТОЧНИК SRC-…
   ↓ CLM-… уверенность medium → low (противоречит CLM-…)
   ↓ HYP-… ослаблена
   ↓ ALT-… оценка «влияние» 4 → 2
   ↓ DEC-… требует пересмотра
   ```
4. Незатронутые артефакты не переписываются. В обновлённых разделах — пометка «пересмотрено по CHG-NNN».
5. Новый выбор (если ранжирование изменилось) снова делает человек.
