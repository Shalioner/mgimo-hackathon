# Интервью и модельные респонденты

Главное правило ТЗ: **синтетические ответы не выдаются за реальные — они не доказывают спрос и распространённость потребности.** Валидатор уже не даёт сделать факт из `synthetic_interview`. Это правило — про текст: в артефактах пиши «модельный респондент сказал…», а не «пользователи говорят…».

## 1. Гайд интервью (T2)
Шаблон: `knowledge/templates/interview_guide.md`. Вопросы строятся от вопросов исследования (`02_research_plan.md`), которые может закрыть только клиент.
- О прошлом поведении, а не о будущих намерениях: «расскажите, как в последний раз…», а не «стали бы вы…».
- Без подсказки ответа и без названия нашего решения в первой половине.
- 5–8 основных вопросов, 30 минут. Для каждого — какой вопрос плана он закрывает.

## 2. Реальные интервью
- **Только с согласия** собеседника (шаблон `knowledge/templates/interview_consent.md`), согласие хранится у команды, не в репозитории.
- **Без персональных данных в репозитории:** роль и сегмент вместо имени («мама, ребёнок 8 лет, Казань»), без телефонов, почты, точных адресов, названий школ. Перед сохранением расшифровки — проверь и вычисти.
- Расшифровка → `sources/interview_NN.md`, регистрация `add-source … --kind interview --access own`.
- Утверждения: `fact` о том, **что сказал** собеседник (с цитатой), а не о мире («R3 сказала, что отключает уведомления по выходным»). Обобщение по нескольким интервью — `interpretation` с `derived_from` и честным `limitations` («5 интервью, не выборка»).
- Частоты («3 из 5») можно указывать только с размером выборки и без процентов при n < 20.

## 3. Модельные респонденты (T1, дёшево)
Зачем: найти гипотезы и неудачные формулировки **до** реальных интервью; проверить, понятно ли сообщение «на слух»; подготовить уточняющие вопросы. Не зачем: оценить спрос, долю, готовность платить.

1. Карточка персоны (`knowledge/templates/synthetic_respondent.md`) строится **только из реестра**: PAIN, CLM, сегмент из брифа. Каждое свойство персоны — со ссылкой на ID или с пометкой «допущение».
2. Беседа ведётся дешёвой моделью: в Claude Code — субагент, иначе `python tools/delegate.py --task synthetic-interview --prompt-file <карточка + гайд> --project … --step 4`. Не больше 3 персон и одного прогона гайда на каждую без согласия человека.
3. Сохрани беседу как `sources/synthetic_NN.md` с шапкой «СИНТЕТИЧЕСКИЕ ОТВЕТЫ…» и зарегистрируй `--kind synthetic_interview --reliability low`.
4. Из беседы извлекаются только **гипотезы** (HYP) и **вопросы для реального интервью**. Если модельный респондент «подтвердил» существующую гипотезу — уверенность гипотезы не повышается.
5. В артефакте — отдельный блок «Модельные респонденты (не доказательство)».

## 4. Анализ (T2)
- Кодирование: темы → цитаты с ID → какие гипотезы усиливают/ослабляют (через CHG, если решение уже принято).
- Противоречия между собеседниками не сглаживаются — две CLM и `contradicted_by`.
- Реальные и синтетические источники в одной таблице не смешиваются.
