# Стратег Фабрики продуктов

ИИ-агент для руководителя цифрового продукта: от размытого запроса до обоснованной продуктовой и коммуникационной стратегии. Агент сопровождает решение и после выбора.

> Не AI, который предлагает стратегию, а AI, который показывает, почему ей можно доверять и когда её нужно изменить.

Это **папка с инструкциями, знаниями и инструментами**, а не отдельная программа. Её открывают в Claude Code, Cursor, Codex или другой агентной среде.

## Быстрый старт (5 минут)

**Нужно:** Python 3.9+ и любая агентная среда с доступом к файлам и терминалу. Веб-поиск — встроенный в среду. Платных сервисов и ключей сверх подписки на саму среду не требуется.

```bash
git clone <ссылка на репозиторий> strategist && cd strategist
```

```bash
python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
```

```bash
python tools/ledger.py status
```

**Windows (PowerShell).** Окружение — `python -m venv .venv; .venv\Scripts\pip install -r requirements.txt`, интерпретатор — `.venv\Scripts\python.exe`. Ограничения: хуки в `.claude/settings.json` и `.codex/hooks.json` вызывают `python3`, а в Windows это часто заглушка Microsoft Store — тогда хуки молча не работают (отключите псевдоним в «Параметры → Приложения → Псевдонимы выполнения приложений» или поставьте Python так, чтобы `python3` был в PATH). В `.mcp.json` указан `.venv/bin/python`; в Windows локально замените его на `.venv\Scripts\python.exe`. Агент работает и без хуков — проверки он запускает сам.

Затем откройте папку в своей среде и напишите агенту задачу обычными словами, например:

> Почему у нашего сервиса X падает удержание и что с этим делать? Вот материалы: …

Инструкции агента — один файл **`AGENTS.md`**, открытый стандарт (Agentic AI Foundation / Linux Foundation). Его нативно читают Codex, Cursor, GitHub Copilot, Windsurf, OpenCode, Gemini CLI и другие.

| Среда | Что подхватывается |
|---|---|
| Codex, Cursor, Copilot, Windsurf, OpenCode и др. | `AGENTS.md` |
| Claude Code | `CLAUDE.md` из одной строки `@AGENTS.md` (Claude Code читает AGENTS.md сам только при отсутствии CLAUDE.md и не во всех версиях — строка-импорт работает везде и не дублирует контекст), навыки `.claude/skills/`, субагенты `.claude/agents/` |
| ZCode | `AGENTS.md` / `CLAUDE.md` (только в приложении ZCode; среду агент определяет командой `ledger.py env`) |

**Хуки.** При старте сессии агент сразу видит состояние проектов, на возражение человека («это не так», «ты не понял», раздражение) он получает подсказку начать с самоаудита, а после каждой записи в реестр автоматически запускается проверка (`.claude/settings.json`, `.codex/hooks.json`). Codex при первом запуске спросит, доверять ли хукам проекта, — это решение человека. Выберите «Trust» или «Continue without trusting»: без хуков агент тоже работает, он просто запускает проверку сам.

Агент сам создаст проект в `projects/<slug>/`, задаст несколько вопросов и пойдёт по шагам. Остановится он трижды, на ваших решениях:
- **C1** — подтвердить постановку задачи;
- **C2** — выбрать вариант;
- **C3** — утвердить пакет стратегий.

**Остановиться и продолжить:** просто закройте чат. В новом чате напишите «продолжи». Агент прочитает `projects/<slug>/state/progress.md` и продолжит с того же места.

**Исправить результат:** отредактируйте любой файл в `outputs/` или скажите агенту, что не так. Ваша версия главнее, агент перенесёт правку в реестр.

**Посмотреть пример:** `python tools/ledger.py impact projects/example CHG-001` показывает, какие выводы учебного кейса затронул новый опрос.

## Что агент выдаёт

`projects/<slug>/outputs/`:
- бриф (`01_brief.md`);
- план исследования (`02_research_plan.md`);
- картина ситуации «известно / откуда / не знаем» (`03_situation.md`);
- варианты с возражениями, включая «оставить как есть» и «закрыть» (`04_options.md`);
- продуктовая стратегия (`05_product_strategy.md`) и коммуникационная стратегия (`06_comms_strategy.md`);
- план проверки (`07_validation_plan.md`);
- журнал решений (`08_decision_log.md`);
- отчёт о времени и стоимости прогона (`09_run_report.md`).

У каждого существенного утверждения в тексте есть ID вида `[CLM-012]`. По ID в `state/ledger/` видно источник, цитату, тип (факт / прогноз / интерпретация / гипотеза) и уверенность.

## Как устроено

```
AGENTS.md            постоянные инструкции: роль, правила доказательности, безопасность, маршрутизация
workflows/           процессы: strategy.md (8 шагов, checkpoints C1–C3), update-decision.md (пересмотр)
skills/              методические навыки по шагам (формат SKILL.md; .claude/skills → skills)
knowledge/templates/ шаблоны артефактов 01–09
schemas/             JSON Schema реестра решения
tools/ledger.py      детерминированные проверки: validate, impact, trace, stats, status, init, add-source
projects/<case>/     sources/ (материалы) · state/ (progress, run_log, ledger) · outputs/ (результаты)
tests/               pytest для инструментов
docs/                ТЗ, требования, модель данных, план, журнал работы
```

## Ключевые решения

1. **Реестр решения вместо чата.** Источники, утверждения, гипотезы, варианты, решения, обещания и эксперименты хранятся связанными YAML-объектами ([docs/DATA_MODEL.md](docs/DATA_MODEL.md)). Это и есть память между сеансами, и в ней прежний ответ агента не становится фактом.
2. **Проверки и пересмотр — кодом, а не моделью.** `ledger.py validate` проверяет:
   - что у фактов есть источники;
   - что цитаты действительно есть в текстах;
   - что в решении есть вариант «оставить как есть» и что выбор сделал человек;
   - что источники не изменились незаметно.

   `ledger.py impact` находит ровно те выводы, которые задели новые данные. Модель переписывает только их.
3. **Деньги под контролем: уровни моделей.** Код (T0) → Haiku/Luna (T1) → Sonnet/Terra (T2) → Opus/Sol (T3) → Fable/Astra (T4, только эскалация и с согласия человека). Уровни общие, а способ переключения свой для каждой среды из ТЗ (Claude Code, Codex, Cursor, Copilot, Windsurf, OpenCode, GigaCode, Кодик): `ledger.py route <задача> --env <среда>`. Из любой среды с терминалом лёгкую подзадачу можно отдать дешёвой модели через `tools/delegate.py` (замер: извлечение цитат на Luna — 9 с и ~25K входных токенов вместо работы основной модели). Журнал хранит фактический уровень и модель каждого шага ([knowledge/routing.yaml](knowledge/routing.yaml)).
   **Новые версии моделей подхватываются сами:** уровни заданы шаблонами (`gpt-*-sol`), `tools/models.py` выбирает новейшую доступную версию и при старте сессии сообщает о новых версиях и устаревших правилах. Правила «когда и как использовать модель» — из официальных руководств Anthropic, OpenAI, Google, Meta, DeepSeek, Qwen, Kimi, Z.ai и Cursor ([knowledge/model_guides](knowledge/model_guides/README.md)); их подсказки автоматически попадают в задания `delegate.py`, а обновляет их навык `skills/model-refresh`. Модель с непредсказуемым именем вносится в [каталог](knowledge/model_catalog.yaml) с указанием, какую модель она сменяет. Специализированные модели (GPT-Rosalind, GPT-5.x-Cyber, финансовые, превью) общий роутинг не выбирает. Эскалация начинается с effort: Opus high → xhigh → только потом Fable; max — только с согласия человека. Свою модель (Ollama/vLLM) можно подключить бэкендом `selfhosted`. Стоимость прогона в деньгах считает `tools/cost.py` по журналам Codex, Claude Code и ZCode и официальным ценам (`knowledge/prices.yaml`). Пример: сквозной прогон `ryadom` в Codex — $3,24 по ценам API.

**Сравнение с обычным чатом** ([evals/baseline/RESULTS.md](evals/baseline/RESULTS.md); протокол зафиксирован до прогона). Тот же кейс, та же модель (Sol medium):

| | Чат + материалы агента | Чат с веб-поиском | Агент |
|---|---|---|---|
| Время / стоимость | 116 с / $0,11 | 157 с / $0,21 | ≈96 мин / $3,24 |
| Рубрика по критериям ТЗ | 10/10 | 10/10 | 10/10 |
| Строки с числами, которые прослеживаются до источника | 11% | 50% | **100%** |

**Пересмотр при новых данных** ([evals/revision/RESULTS.md](evals/revision/RESULTS.md)): по содержанию — паритет (эталон 6/6 у обоих), чат $0,10 / 67 с, агент $0,49 / 6 мин. Но у чата новые выводы — отдельное сообщение рядом со старым пакетом без пометок об устаревании, а агент обновил документы и реестр на месте: запись изменения CHG, «было → стало», решение со статусом «под вопросом» и возврат человеку на C2. После исправлений (прогон 2) агент правит устаревшие абзацы внутри документов: `verify.py --change` не находит ни одной необновлённой строки (было 47). Пересмотр на модели уровня T2 (Terra) — **$0,30** против $0,81–1,02 на Sol при том же эталоне и проверках, поэтому маршрут `impact-revision` теперь T2.

Разовый текст стратегии хорошая модель в чате пишет не хуже и намного дешевле. Агент выигрывает в другом: каждое число ведёт к объекту реестра и сохранённой копии источника, работа продолжается после перерыва, при новых данных пересматривается только затронутое, а решения и расходы видны в журнале. Цена агента — главный долг (см. [docs/CRITERIA.md](docs/CRITERIA.md)).

**MCP.** Те же инструменты доступны как MCP-сервер `strategist` (`tools/mcp_server.py`, без зависимостей): `.mcp.json` подхватывает Claude Code (при первом запуске попросит одобрить сервер), `.cursor/mcp.json` — Cursor. В Codex сервер подключается глобально — по решению пользователя: `codex mcp add strategist -- <путь>/.venv/bin/python <путь>/tools/mcp_server.py`. Классификацию (тип утверждения, поддержка источником, уровень подзадачи) делает **модель решений** через `tools/decide.py` — TypeSafe Jev через OpenRouter/Requesty или открытый аналог на своём сервере (протокол System One). Она возвращает вероятности, а LLM разбирает только неуверенные ответы. Ключ — в `OPENROUTER_API_KEY`. Без ключа тот же протокол работает на дешёвой LLM (Luna/Haiku, effort low) — медленнее и дороже Jev, но с той же логикой. Перед каждым checkpoint артефакт проходит **проверку готовности** (`decide.py --gate`): вопросы «да/нет» по правилам и готовые подсказки, что исправить. Дешёвая модель исправляет брак сама, а к дорогой агент переходит только после двух неудачных попыток.
4. **Один оркестратор и узкие помощники, а не рой агентов.** Субагенты только там, где они дешевле основной модели: `source-extractor` и `claim-verifier` на Haiku.
5. **Человек решает.** Агент рекомендует, выбор и ответственность за человеком (checkpoints C1–C3).
6. **Безопасность.** Используются только открытые и собственные материалы. Текст источников — данные, а не инструкции. Ключей в репозитории нет (`.env.example`).
