# Отчёт о прогоне

| Показатель | Значение |
|---|---|
| Среда и модель(и) | claude-code; основной агент GLM-5.3-Flash (в среде недоступны субагенты на Haiku — уровни T1/T3 выполнялись текущей моделью) |
| Время работы агента | одна сессия ~1 час (шаги 1–8) |
| Время человека (ответы на checkpoints, правки) | 3 ответа: C1 (сужение сегмента, цель, горизонт), C2 (выбор ALT-001 + требование перепроверить цены), C3 (утверждение, владелец, срок разбора пилота) |
| Поисков / прочитанных источников | 6 поисковых раундов суммарно; полностранично прочитано и сохранено 7 источников (6 веб + официальный сайт МегаФона) |
| Стоимость (токены / ₽ / $) | ориентир ~110K токенов суммарно (основной агент ~60K + субагент-верификатор ~412K токенов по счётчику среды — исключая кэш); среда точную стоимость не показывала |
| Ошибки инструментов и как обойдены | WebFetch: 403 на moscow.megafon.ru → получено curl с браузерным User-Agent; Telna 404 и ошибка сети Thales → Q4 (удержание) остался частичным пробелом, закрытие перенесено в EXP-002; YAML-ошибки валидатора (двоеточия в скалярах) → исправлены кавычками |
| Сколько раз понадобилась помощь человека и зачем | 3 раза, все — обязательные checkpoints C1–C3 (по регламенту), плюс внутрипроектное требование верификации цен |

| T1 | рекомендован Haiku | извлечение CLM (шаг 3) + верификатор (шаг 7, субагент general-purpose) | ~412K (верификатор) + извлечение текущей моделью | среда не дала субагент на Haiku — выполнено текущей моделью/субагентом по умолчанию |
| T2 | рекомендован Sonnet | шаги 1, 2, 7 (план проверки) | ~40K | среда не дала выбрать модель |
| T3 | рекомендован Opus | шаги 5, 6 (варианты, стратегии) | ~30K | среда не дала выбрать модель |
| T4 | — | 0 | — | не требовался |

## Ограничения результата
- Только открытые источники: внутренние данные МегаФона (доля утечки, роуминговая выручка) не использовались — пробел закрывается EXP-001 и внутренней аналитикой.
- Q4 (удерживает ли travel eSIM оператора абонентов) не закрыт метриками — ключевой риск цели «удержание»; проверяется пилотом EXP-002 с численными порогами stop/go.
- Цены агрегаторов частично из нативных рекламных статей (SRC-005, SRC-006, надёжность low) — перед докладом перепроверить прайсы 2–3 агрегаторов напрямую.
- Прогноз рынка (CLM-001) — оценка Juniper; альтернативные оценки различаются ($1,8–3,3 млрд на 2025).
