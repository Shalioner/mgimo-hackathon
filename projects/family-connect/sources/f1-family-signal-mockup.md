# Текстовый макет F1 для закрытой проверки

Сценарий: действующее разрешение участника, подходящий тариф, свежие сведения, есть свободный общий остаток. Используются вымышленные номера и события.

**В макете показано допустимое действие: открыть проверку, чтобы узнать, можно ли выделить интернет.**

После нажатия в учебном сценарии показываются получатель и объём для проверки. Надпись «итог проверяется» означает ожидание, в сценарии с подтверждением показывается итог. Макет не совершает операции. При истёкшем согласии, устаревшем остатке или неясной причине карточка не показывает чужие сведения.
