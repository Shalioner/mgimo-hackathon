# Сравнение полного маршрута с фиксированной моделью

Статус: план, не результат. Подготовлен 2026-11-15; модельные прогоны не запускались.
Короткие D1 smoke и сравнение разных объёмов документов не заменяют этот эксперимент.

## Что фиксируется до запуска

- Snapshot кода, SHA-256 входов, версии промптов, модель и effort каждого вызова.
- Одна задача, источники, критерии результата и доступные инструменты для обеих веток.
- Контроль: фиксированная модель уровня задачи. Routing: D1, последовательное извлечение
  T1, выбранная модель синтеза. Недоступность маршрута фиксируется как отказ, без
  скрытой замены аккаунта/API и без исключения неудач из сравнения.
- Набор: простое извлечение; сравнение документов; нерелевантный документ внутри пачки;
  полностью нерелевантная пачка; конфликт периодов/сегментов; сравнение вариантов;
  новая задача после эскалации; ошибка инструмента с повторным чтением.
- Одинаковые checkpoints и имитационные ответы человека для лабораторной проверки.
  Такие ответы не являются согласованием реального проекта.
- По одному запуску каждой ветки на сценарий, порядок веток чередуется. Повторные
  попытки считаются дополнительными затратами, не заменяют неудачный результат.

## Что измеряется

По сценариям и суммарно: успешность, пропущенные смысловые ошибки, ложные отказы,
доля неуверенных решений D1, ручные вмешательства, полное время, input/output/cache/
reasoning токены, расходы и число вызовов инструментов. Учитывать классификацию,
извлечение, синтез, проверки, исправления, повторное чтение и неудачные вызовы.
Неизвестное значение — null с причиной, не ноль.

Экономия токенов: `1 - routed_total_tokens / baseline_total_tokens` при ненулевом
baseline. Деньги считать отдельно по подтверждённому тарифу и ценовому snapshot;
подписочные токены не выдавать за фактические списания API. Локальный D1 тоже имеет
задержку и потребление памяти; отсутствие API-счёта не означает отсутствия затрат.

Предлагаемый барьер: не потерять существенные выводы относительно контроля, не
пропустить неподтверждённое обещание/неверное основание, не нарушить квоту или
разрешения. Экономию объявлять для сопоставимого качества, отказы показывать отдельно
и в общем числе задач. Бюджет и допустимая задержка согласуются до модельного запуска;
платные вызовы этим документом не разрешены.

## Бесплатная подготовка

```bash
.venv/bin/python -m pytest tests/test_document_flow.py tests/test_codex_routing_hook.py tests/test_install_host_routing.py tests/test_tool_context.py -q
.venv/bin/python evals/semantic/score.py
```

Это механические проверки с подменой транспорта и проверка корпуса. Вывод pytest
не заполняет таблицу экономии и не является измерением качества D1/LLM. Следующий
этап — зафиксировать конкретные входы, пройти одинаковый пользовательский путь и
сохранить сырые receipts обеих веток без секретов.
