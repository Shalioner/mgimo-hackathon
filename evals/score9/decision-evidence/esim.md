# Решение сегодня

eSIM-travel: что предложить сегодня вместо обещания работы на всех iPhone?
Область: iPhone Dual SIM, два разных оператора

Что предлагаем руководителю: Добавить проверку разблокировки в прототип входа, снять универсальное обещание. Стоп до закупки/интеграции; Android требует другого источника.
Основание приоритета (допущение): Допущение сценария: широкий доступ предпочтителен при технической допустимости; иначе ограничить прототип проверкой совместимости. Коммерческий запуск не оценивается.
Это допуск к указанному действию, не доказательство спроса, эффекта или окупаемости. Выбирает человек.

## Действия
- TODAY-01 [excluded]: Предложить безусловную совместимость для всех iPhone без проверки оператора.
  Возражение: Заблокированные устройства могут не подключиться. Условия против: ['unlock_required']; неизвестно: [].
- TODAY-02 [eligible]: Добавить проверку разблокировки в прототип входа, снять универсальное обещание. Стоп до закупки/интеграции; Android требует другого источника.
  Возражение: Неизвестно, какая доля нашей базы пройдёт проверку. Условия против: []; неизвестно: [].
- TODAY-03 [eligible]: Сохранить текущий роуминг без новой функции.
  Возражение: Можно упустить полезный сегмент. Условия против: []; неизвестно: [].
- TODAY-04 [eligible]: Предложить закрытие инвестиций travel eSIM.
  Возражение: Неизвестный эффект нельзя считать нулевым. Условия против: []; неизвестно: [].
- TODAY-05 [conditional]: Предложить ограниченный коммерческий пилот только на совместимых устройствах после проверки эффекта, затрат, условий поставщика и лимита.
  Возражение: Документация Apple не даёт оснований для коммерческого пилота. Условия против: []; неизвестно: ['retention'].

## Какие открытые данные меняют выбор
- CLM-D03 [unlock_required=True]: Apple требует разблокировку для двух разных операторов; безусловная совместимость исключена.
  Без этого сведения изменится допуск к действию: Предложить безусловную совместимость для всех iPhone без проверки оператора. / Добавить проверку разблокировки в прототип входа, снять универсальное обещание. Стоп до закупки/интеграции; Android требует другого источника..
  Рекомендация изменится.
  Источник: https://support.apple.com/en-us/109317 (What you need); снимок sources/apple.txt. Ограничение: Не показывает состав нашей базы, спрос, удержание или стоимость white-label.
