**Два следствия для проверки сигнала об исчерпании интернета**

1. **Отдельный отрицательный контроль полномочий.** Остаток получателя исчерпан, в общем пакете есть ГБ, участник вправе видеть остаток, а право выдачи ему явно не предоставлено. Проверить, что допущенный к просмотру участник получает сигнал, а попытка выдачи отклоняется из-за отсутствия полномочия.
2. **Отдельная проверка нулевого общего остатка.** Остаток получателя исчерпан, участник вправе видеть остаток и выдавать ГБ, общий пакет существует, его остаток равен нулю. Проверить отказ из-за нехватки ГБ и понятность этой причины в интерфейсе.

Данных о влиянии сигнала на действия пользователей нет.

**Два следствия для проверки сигнала об исчерпании интернета**

1. **Проверить доступ к остатку и полномочие на выдачу раздельно.** Сигнал видит только участник с правом видеть остаток другого номера. Отдельный отрицательный контроль для выдачи — получатель сигнала вправе видеть остаток, но полномочие на выдачу не подтверждено. Ожидаемый результат — выдача отклонена.
2. **Различить нулевой остаток участника и нулевой общий остаток.** Для продукта с общим пакетом проверить два случая при подтверждённом полномочии на выдачу. Если остаток участника исчерпан, а в общем пакете есть достаточно ГБ, сигнал может предложить выдачу. Если общий остаток равен нулю, ожидается отказ в выдаче с указанием причины.

Эти сценарии проверяют корректность сигнала и выдачи. Данных об эффективности сигнала в выдержках нет.
