# Что добавил Стратег к ответу перед встречей с директором

«Мне через час к директору. Что изменилось по доставке B, можно ли подтверждать заказ и что конкретно делаем дальше?»

В двух отдельных сессиях Sol 6.1 high получил одинаковые учебные данные и этот вопрос. В одной сессии модели были доступны инструкции и инструменты Стратега. Третий агент оценил обезличенные ответы по четырём заранее записанным признакам.

| Ответ | Режим | Баллы |
|---|---|---:|
| [X](X.md) | Обычный чат с файлами | 2/4 |
| [Y](Y.md) | Стратег с файлами | 4/4 |

Оба правильно посчитали **185 доставок из 200 назначенных за семь дней** и сохранили запрет на заказ. Обычный чат дал готовую фразу подрядчику. Стратег также напомнил, какой тест уже выбрал директор, и указал документ, где тот разрешил только запрос статистики. Эти два признака объясняют весь разрыв. Время и количество реальных уточнений сотрудников в этой пробе не измерялись.

Для собственной проверки откройте [первую выгрузку](первая_выгрузка.csv), [поправку](поправка.csv), [письмо подрядчика](письмо.txt) и [решение директора](решение.txt). Сравните два ответа по [исходному протоколу](protocol.md), затем откройте [оценку по каждому признаку](judgement.md). Это один синтетический пример.
