# Учебный протокол проверки кабинета
Дата 22 ноября 2026 года. Собственный синтетический вход. Протокол относится только к тестовому кабинету и четырём шагам ниже, без сведений о полевом эффекте.
- Тестовая запись R-110 назначена пользователю U-01. В авторизованном личном кабинете U-01 видит собственную бронь и кнопку «Перенести».
- После выбора свободного слота показано «Запись перенесена». Во вкладке «Мои записи» остался один активный слот. При попытке переноса в занятый слот для записи R-111 исходная бронь сохранилась.
- Пользователь U-02 не получил доступ к брони U-01. После отключения напоминаний контрольная отправка для U-01 не состоялась.
Проверка подтверждает только то, что в тестовом кабинете свою запись можно перенести на доступный слот. Допуск реальных пользователей, полную смету и доступность во всех случаях она не подтверждает.
