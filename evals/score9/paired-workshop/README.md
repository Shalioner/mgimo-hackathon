# Новый кейс «Запись на онлайн-практикум»

Обычный чат с терминалом и Стратег прошли одинаковые пять реплик на GPT-6.2 Sol medium. Бриф, таблица и сценарные решения руководителя синтетические. Модель увидела исправленную выгрузку только в отдельном новом чате. Протокол, хэши и фактические ответы сохранены. [Протокол](pair_protocol.md) · [Одинаковые входы](inputs/) · [Ответы обеих сторон](TRANSCRIPTS.md) · [Зафиксированные условия](frozen.json)

## Решение после поправки

Оба режима пересчитали +9 п.п. до +3 п.п. и 4% обращений до 6%. Оба остановили следующую волну и вернули выбор сценарному руководителю. Стратег в исходном парном прогоне отказался записывать C3 без прямого подтверждения переноса. Это наблюдаемый результат проверки, включая незакрытое согласование. Дополнительный контроль ниже использует отдельный источник.

Слепой оценщик проверил ответы и сохранённые материалы по восьми заранее заданным пунктам. Обычный чат получил **8/8**, Стратег **7/8**. У Стратега не закрылся пункт 6 о зарегистрированном утверждении. Критических провалов не было. Сохранённые тексты могут выдавать режим по структуре файлов и терминологии. [Подробная сверка](BLIND_REVIEW.md)

Время — сумма продолжительностей запусков CLI. Были паузы между отдельными процессами, они в таблицу не входят. Первоначально у обоих режимов запуск второй реплики отклонялся до вызова модели из-за неподдерживаемого параметра CLI. Параметр убрали, сохранив первую реплику, контексты и сообщения. API-эквивалент рассчитан по видимым счётчикам и сохранённому тарифу из `knowledge/prices.yaml`. Использована подписка ChatGPT, активное время человека не измерялось. Реплики подавал скрипт. Число ошибок включает исправленные ошибки команд. Это одна пара, без оценки разброса. [Счётчики и окна](metrics.json) · [Поправка запуска](runner-repair.json)

Codex CLI 0.171.0 передаёт в `turn.completed.usage` накопительный итог по чату. Первоначальный экспорт завысил эквивалент, сложив четыре промежуточных снимка первого чата. Пересчёт берёт последний снимок каждого чата один раз. Все пять снимков и метки двух чатов сохранены. [Код CLI 0.171.0](https://github.com/openai/codex/blob/rust-v0.171.0/codex-rs/exec/src/event_processor_with_jsonl_output.rs#L109-L119) · [Экспортёр](export_pair.py)

Стратег в паре работал с деревом `d1a0d03` и двумя изменёнными файлами проверки пропущенных исходов, указанными в `frozen.json`. Остальные исправления проверены отдельно на финальном локальном кандидате. [Воспроизводимые контроли](../../../docs/DECISION_RECHECK.md)

## Отдельный контроль с дополнительным источником

После добавления учебной квитанции о переносе Стратег предъявил версию, зарегистрировал сценарное C3 и в новом чате потребовал повторного C2. Сохранены обе версии состояния и байты первоначальной квитанции. [Сквозной путь согласования и пересмотра](POSITIVE_CONTROL.md)

Отдельная локальная проверка на снимке до добавления квитанции подтверждает, что руководитель может явно утвердить только внутреннюю диагностику. Исторический парный результат выше сохраняется. [Как воспроизвести](../../../docs/DECISION_RECHECK.md#внутреннее-согласование)
