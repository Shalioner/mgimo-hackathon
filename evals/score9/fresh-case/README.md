# Когда руководитель отклонил готовый пакет

«Стежок» — учебная задача о записи в общую швейную мастерскую. Стратег работал в реальных модельных сеансах и обращался к локальным инструментам. Все реплики владельца были заранее обозначены как сценарные.

**Статус пакета после продолжения — исправленная версия согласована сценарным владельцем.** В предъявленной стратегии сохранена фраза о состоянии до согласования. Последующее согласие относится к SHA `39955df2…`; редактирование предъявленного документа изменило бы его отпечаток. [Квитанция версии](stezhok/state/c3_approvals.json) · [Точка продолжения](stezhok/state/progress.md)

1. Откройте [продуктовую](05_product_strategy.html) и [коммуникационную стратегии](06_comms_strategy.html), затем [план проверки](stezhok/outputs/07_validation_plan.md).
2. Сверьте допустимое обещание с [реестром обещаний](stezhok/state/ledger/promises.yaml), [утверждениями](stezhok/state/ledger/claims.yaml) и [материалами проверки](stezhok/sources/).
3. Сравните [зафиксированный отказ](stezhok/state/c3_refusal_synthetic.txt) с [последующим ответом](stezhok/state/c3_approval_synthetic.txt). Из корня установленной поставки выполните `.venv/bin/python tools/c3_approval.py check evals/score9/fresh-case/stezhok --json`. У согласованной версии ожидаются `current` и пустой список изменений.
4. Для отрицательного контроля распакуйте [исходное состояние](initial-case.zip) в отдельную временную папку. Из корня поставки выполните `.venv/bin/python tools/c3_approval.py prepare /путь/к/initial`. Ожидается отказ с кодом 2. Состояния можно проверить офлайн.

Первый проход закончился двумя черновиками стратегий. Агенту не хватало подтверждённой функции для обещания посетителям и основания для оценки затрат. Утверждение пакета осталось открытым.

В продолжении появился работающий лабораторный инструмент оформления карточек. Стратег проверил его и ограничил обещание этим действием. Когда сценарный владелец отклонил первую готовую версию, агент сохранил отказ. После корректировки отдельная реплика одобрила только исправленную версию. Новый сеанс восстановил именно её. Эксперименты и пилот оставались без исполнения.

[Ответ при отказе](live-session3-refusal.md) · [Ответ после перерыва](live-session5-restart.md) · [12 проверенных условий](independent-assertions.json)

Первый проход занял 36 мин 12 с с API-эквивалентом $2,1612. Окно продолжения — 32,83 минуты, API-эквивалент трёх сессий $2,1694. Это оценки по журналам, без стоимости работы координатора. Полевой спрос и действия реального директора в эксперименте не измерялись.
