# Картина ситуации: что позволяют открытые правила

## Главное
У открытых аналогов заявка, подтверждённая бронь и допуск к машине могут быть разными состояниями [CLM-004] (interpretation, medium).
Это позволяет проверять безусловные обещания, но не доказывает перспективы «Стежка».
Правило на случай опоздания не измеряет распространённость неявок [CLM-005] (interpretation, high).
Главный пробел — местные условия и поведение; уверенность в правомерности переноса на «Стежок» низкая.

СИНТЕТИЧЕСКИЙ УЧЕБНЫЙ ПРОГОН. Данные источников открытые и реальные; подтверждение брифа — только внутри сценария.

**Счётчик по ledger.py stats:** 5 фактов / 6 интерпретаций / 2 гипотезы / 2 допущения / 0 противоречий; 6 источников, из них 3 открытых и 3 собственных; отдельно 3 исходных пробела и новый пробел фактического труда/полезности.

## Q1. Есть ли проверяемые границы обещаний?
- **Известно:** в LSC-CyFair заявка требует официального подтверждения [CLM-001] (fact, high); Springvale Library требует инструктаж перед работой на швейной машине [CLM-003] (fact, high).
- **Интерпретация:** обещания «отправил заявку — машина гарантирована» и «запись сама даёт допуск» требуют собственных подтверждённых условий [CLM-004] (interpretation, medium). Примеры не объявлены обещаниями владельца: они составлены агентом для проверки границ.
- **Неизвестно:** какое подтверждение, доступ и подготовку сможет обеспечивать «Стежок». **Почему:** собственной мастерской и ресурсов в данных нет. **Как узнать:** сейчас сохранить требования к свидетельству; получение собственных условий — отдельная будущая задача, не контакт с оператором в этом исследовании.

## Q2. Обоснован ли приоритет борьбы с неявками?
- **Известно:** MakerSpace допускает освобождение машины при опоздании пользователя [CLM-002] (fact, high).
- **Интерпретация:** наличие правила не доказывает частоту события или эффект санкций [CLM-005] (interpretation, high).
- **Неизвестно:** сопоставимая частота неявок и причинный эффект правил для жителей «Стежка». **Почему:** нет собственных событий; в выполненном ограниченном поиске найдены прежде всего политики и исследования иных сред, без принятого сопоставимого знаменателя. **Как узнать:** для продолжения кабинетного поиска нужен первичный материал с определением события, периодом и знаменателем; местную частоту открытые документы аналогов не заменят.

## Боли клиентов
[PAIN-001] — только возможная трудность отличить заявку от подтверждённого допуска [HYP-002] (hypothesis, low). Частота, стоимость, обходные пути, незакрытость и измеримость — unknown. Это не обнаруженный сегмент, не мнение жителей и не доказанный спрос.

## Возражение к основаниям
Наиболее связующий вывод — CLM-004: он объединяет правила разных операторов. Его medium-уверенность допустима только для поиска требований к доказательству, а не для переноса этих требований как действующих правил «Стежка». Публичные правила не гарантируют их фактического исполнения. Локальный снимок и точная цитата проверяют происхождение, а не причинность.

## Ограничения
- Найденные документы первичные для правил их операторов, не для потребностей наших жителей. Размер рынка не установлен; появилась только условная модель труда внутреннего разбора [HYP-004; CLM-010] (assumption и interpretation, low; пересмотрено по CHG-001).
- Неизвестно: реальное усилие и полезность следующего исследования. Почему: команда и оценки времени отсутствуют. Как узнать: принять либо изменить порядковую модель на C2; не называть выбранный шаг дешёвым пилотом.
- Поиск ограничен, не систематический обзор: отсутствие принятого измерения не доказывает отсутствие таких работ. Противоречий между разными областями правил не выявлено.

## Новое собственное свидетельство (CHG-001)
**Факт:** локальный CLI оформил заполненную карточку в Markdown и отклонил неполную [CLM-008] (fact, high).
**Факт о пределе:** ложная, но заполненная карточка прошла; истинность и пригодность обещания инструмент не проверяет [CLM-009] (fact, high).
**Интерпретация:** допустимый кандидат внутреннего сообщения — «получить Markdown из вручную заполненной карточки», только локальный CLI, а не «получить проверенное честное обещание» [CLM-008; CLM-009]. Это кандидат, PRM ещё не активирован; повторный синтетический C2 завершён, пакет ожидает C3 [DEC-001] (пересмотрено по CHG-001).
**Допущение:** лимит труда 2 часа, оценка 1000 рублей/час и прямой доход 0 рублей/разбор — сценарий лаборатории [HYP-004] (assumption, low). Потолок 2000 рублей — расчёт допущения, не реальный бюджет [CLM-010] (interpretation, low).
