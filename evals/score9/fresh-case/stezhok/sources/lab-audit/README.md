# Новое собственное свидетельство лаборатории
СИНТЕТИЧЕСКИЙ УЧЕБНЫЙ АРТЕФАКТ, не полевой продукт.
Наблюдаемая возможность: локальный CLI превращает заполненную вручную карточку обещания, источника, границы и недостающего свидетельства в Markdown. Проверяет лишь наличие четырёх непустых полей. Не проверяет истинность, полноту аудита или пригодность обещания.
Команда: python audit.py --input example.json --output report.md. Пример и отказ на неполных полях реально выполнены; observed-tests.json. Агенту следует независимо повторить проверку.
Условные вводные лаборатории для ограниченного внутреннего использования: один синтетический аналитик, лимит труда 2 часа на один внутренний разбор, условная оценка часа 1000 рублей/час, прямой денежный доход 0 рублей на разбор. Это сценарные допущения, не цены рынка, не выделенный реальный бюджет и не прогноз спроса. Расход труда ограничен 2000 рублей на разбор при этих допущениях; реальный труд не замерен. Новые API, платежи, контакты и публикации не разрешены.
Свидетельство не меняет автоматически C2. Новый собственный инструмент может быть основанием пересмотра по существующим review_triggers; выбор и предел вывода определяет Стратег, новые C1/C2 при необходимости — отдельные сценарные ответы.
