# Служебная поправка к сводке

Учебный аудит сверил сводку с повторной маркировкой и журналом обращений. В первой выгрузке загрузчик мог брать зону назначения вместо фактической зоны на приёмке и не связывал обращения, зарегистрированные на втором рабочем экране. Пересчёт проверил каждую запись по идентификатору исходной операции.

Файл `pilot-corrected.csv` заменяет `pilot.csv` для обеих метрик. Это те же операторы, ветки, склад и 24-часовое окно. Итоговая сводка полная. Смета, критерии решения, ограничения допуска и наблюдение на учебном стенде остаются действующими.
