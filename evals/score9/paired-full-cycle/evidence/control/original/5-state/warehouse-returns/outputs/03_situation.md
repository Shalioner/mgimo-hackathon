# Картина ситуации

## Главное

После исправления сводки выигрыш подсказки составил +2 п.п. при минимуме +5 п.п. Доля обращений в тесте достигла 7% при пороге 5%. Сработал Stop по обращениям [CLM-004] [CLM-016].
Уверенность в арифметике высокая. Интервалы пересекают оба порога. Они оставляют полезный эффект возможным, а операционный Stop срабатывает по наблюдаемой доле обращений [CLM-004] [CLM-017].
Для этикетки пока нет сравнимого результата, а стоимость пересортировки неизвестна [CLM-001] [CLM-005].

**Сверка версий.** Учебный аудит исправил подстановку зоны назначения вместо фактической зоны приёмки и учёт обращений со второго экрана. Склад, ветки, операторы и окно совпадают. Исправленная сводка заменяет прежнюю для обеих метрик [CLM-014] [CLM-015].

## Q1. Исходы пилота [R2]

**Известно.** На одном учебном складе операторов случайно распределили по веткам. В знаменатель входят все назначенные операторы. Оператор представлен своим первым подходящим закрытым коробом. Типы подходящих возвратов совпадали. Окно по каждому исходу — 24 часа. Пропусков и дублей нет по описанию, сама таблица агрегирована по веткам [CLM-002] [CLM-003].

| Исход | Текущий экран | Подсказка | Разница |
|---|---|---|---|
| Правильная зона без повторной маркировки | 216 / 300 = 72% [CLM-015] [CLM-016] | 222 / 300 = 74% [CLM-015] [CLM-016] | +2 п.п. [CLM-016] |
| Хотя бы одно обращение к начальнику смены | 6 / 300 = 2% [CLM-015] [CLM-016] | 21 / 300 = 7% [CLM-015] [CLM-016] | +5 п.п. [CLM-016] |

**Интерпретация.** Процент — счётчик исхода, делённый на `assigned` в той же ветке. Разница — доля теста минус доля контроля. Для вреда сравниваем с порогом абсолютные 7% в тесте. По сводке и описанию известны исходы всех 600 назначенных, доля пропусков 0% [CLM-003] [CLM-004] [CLM-015] [CLM-016].

Для разницы качества двусторонний 95% интервал Ньюкомба от −5,09 до +9,07 п.п. Для доли обращений в тесте двусторонний 95% интервал Уилсона от 4,62% до 10,46%. Для воспроизведения границ разницы строим интервалы Уилсона для обеих долей через `tools/power.py wilson`. Из разницы долей вычитаем корень из суммы квадратов расстояний до нижней границы теста и верхней границы контроля. Для верхней границы прибавляем корень из суммы квадратов расстояний до верхней границы теста и нижней границы контроля [CLM-017].

**Неизвестно.** Какой выигрыш дала бы подсказка при повторе и почему операторы обращались к начальнику смены. Для проверки нужны сверка случаев по операциям и отдельно согласованный дизайн. Уверенность в гипотезе о совместном прохождении порогов снижена [CLM-006] [CLM-016] [CLM-017] [HYP-001] (пересмотрено по CHG-001).

## Q2. Готовность и причина ошибок

**Известно.** Стенд показал код после ручного подтверждения зоны и до закрытия короба. Без подтверждения кода нет. Этикетку с операторами ещё не проверяли. Подготовка и стенд допустимы, для проверки на реальных сменах нужно отдельное согласование [CLM-001] [CLM-006] [CLM-007].

**Интерпретация.** Стенд подтверждает поведение интерфейса. Для выбора между экраном и этикеткой важно выяснить момент ошибки [HYP-002].

**Неизвестно.** Как часто ошибки возникают при чтении физической этикетки. В сводке нет этапа и причины ошибки. Это можно установить по наблюдениям за маршрутом короба и разбору случаев пересортировки [HYP-002].

## Q3. Экономика

**Известно.** Смета на неделю составляет 36 000 ₽ при потолке 50 000 ₽ [CLM-005].

**Интерпретация.** Запас по смете составляет 14 000 ₽. Из исходов пилота нельзя напрямую вывести денежную выгоду [CLM-011].

**Неизвестно.** Чистый вклад подготовки подсказки, этикетки и высвобождения ресурса. Нужны стоимость повторной маркировки, оценки работ по вариантам и ценность альтернативной задачи команды [CLM-005] [CLM-011].

## Проблема оператора и гипотезы

У операторов возвратов возникают короба, которые не проходят приёмку в правильной зоне без повторной маркировки. Частота исхода и обращения измеряются. Стоимость для оператора и результат обращения не измерены [PAIN-001].
Пересчёт снимает основание для немедленной подготовки повтора подсказки. Вопрос о моменте возникновения ошибок остаётся открытым [CLM-016] [HYP-001] [HYP-002] (пересмотрено по CHG-001).
