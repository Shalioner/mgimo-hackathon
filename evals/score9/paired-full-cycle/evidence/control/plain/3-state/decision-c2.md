# C2 — Выбор проверки для сортировки возвратов

**Статус.** Сценарный руководитель подтвердил [бриф C1](brief-c1.md). Выбор ниже представлен на C2 и ждёт подтверждения.

## Выбор

Подготовить материалы и стендовую проверку подсказки с кодом зоны для одного склада. Для возможной следующей проверки на сменах сохранить текущий экран в качестве контроля. Разрешение на работу на реальных сменах отдельно дают руководитель продукта и начальник склада.

## Пересчёт пилота

Пилот прошёл 9–15 ноября 2026 года на одном учебном складе. Знаменатель для обоих исходов — все распределённые операторы в каждой ветке. Случайное распределение и анализ проводились на уровне оператора. У каждого учтён первый подходящий закрытый короб при одинаковых критериях допуска и полном окне наблюдения в 24 часа.

| Ветка | Распределено | Принято в правильной зоне без повторной маркировки | Хотя бы одно обращение к начальнику смены по операции |
|---|---:|---:|---:|
| Текущий экран | 300 | 216 / 300 = 72% | 6 / 300 = 2% |
| Подсказка | 300 | 240 / 300 = 80% | 9 / 300 = 3% |
| Подсказка минус текущий экран | | +8 п.п. | +1 п.п. |

- Наблюдаемый выигрыш +8 п.п. превышает заданный минимум +5 п.п. на 3 п.п. Приблизительный 95%-й доверительный интервал для разницы долей по нормальному приближению составляет от +1,2 до +14,8 п.п. Внутри интервала есть значения ниже +5 п.п., поэтому точность оценки ограничена.
- Доля обращений в тестовой ветке 3%, на 2 п.п. ниже 5%. Правило остановки расширения срабатывает при доле строго выше 5% в тестовой ветке.
- Смета работ на неделю 36 000 ₽ при потолке 50 000 ₽. Запас 14 000 ₽. Для расчёта экономии нужна стоимость повторной маркировки на короб.
- В CSV проверены две ожидаемые строки, по одной на ветку, положительные знаменатели и допустимые счётчики исходов. Полнота наблюдения, отсутствие дублей операторов и соблюдение условий распределения указаны в описании пилота. CSV содержит агрегаты по веткам, поэтому эти свойства нельзя перепроверить по отдельным записям.

## Сравнение вариантов

| Вариант | Что известно | Решение на ближайшую неделю |
|---|---|---|
| Оставить текущий экран | 72% коробов приняты в правильной зоне без повторной маркировки, 2% операторов обратились к начальнику смены. | Использовать как контроль. Сам по себе этот вариант сохраняет текущий процесс. |
| Проверить подсказку на одном складе | +8 п.п. по основному исходу, обращения у 3% тестовой ветки, смета в пределах потолка. На стенде после ручного подтверждения R-12 код виден до закрытия короба. Без подтверждения подсказка не появляется. | Выбрать подготовку материалов и проверку на стенде. |
| Изменить печатную этикетку | Этикетку с операторами ещё не проверяли. Данных о её влиянии на сортировку и обращения нет. | Отложить. Если вернёмся к варианту, начать с проверки этикетки с операторами. |
| Остановить инициативу и вернуть ресурс | Освобождает ресурс команды. В текущем пилоте достигнут порог наблюдаемого выигрыша, порог вреда не превышен, смета укладывается в лимит. | Продолжить подготовку ограниченной проверки. При сигнале вреда приостановить расширение до отдельного решения. |

Результат относится к одному складу. Стенд подтвердил только показ кода и условие его появления. Скорость и переносимость результата на другие склады остаются непроверенными. Формулировка для операторов должна описывать показ вручную подтверждённого кода зоны до закрытия короба.
