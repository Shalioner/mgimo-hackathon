# Продуктовая стратегия

## Главное

Подготовка экранной подсказки поставлена на паузу после сигнала вреда. Для учебной недели предложено сохранить текущий экран [CLM-003] [CLM-018] [DEC-001] (пересмотрено по CHG-001).
Польза ниже порога, обращения выше порога. Оценка экономии требует данных о повторной маркировке [CLM-004] [CLM-017] [CLM-018].
Если руководитель выделит ресурс на диагностику, доступны подготовка и стенд в рамках заданного потолка. Реальные смены требуют отдельного допуска [CLM-001] [CLM-004] [CLM-005].

**Решение.** Прежний выбор руководителя ALT-001 вынесен на повторный C2 [DEC-001] (пересмотрено по CHG-001).

## Альтернативы для аудитории

На текущем экране действует существующая процедура. В исправленной сводке доля обращений выше в ветке подсказки, причины роста неизвестны. Применимость этикетки зависит от этапа ошибки [CLM-001] [CLM-018] [HYP-002] (пересмотрено по CHG-001).

## Выбранное направление

В прежнем варианте функция показывала код вручную подтверждённой зоны перед закрытием. Стенд подтвердил совпадение кода, видимость до закрытия и отсутствие строки без подтверждения [CLM-012].

[R5] Подготовка экранного текста и будущего сравнения ждёт повторного C2. Для возможного возврата к плану нужны сверка регистрации исходов, проверка набора и сметы, затем отдельный допуск руководителя продукта и начальника склада [CLM-001] [CLM-004] [CLM-005] [CLM-014] [DEC-001] (пересмотрено по CHG-001).

## Осознанные отказы

- Охват ограничен выбранным складом и первым подходящим коробом. Данных о переносимости на другие склады и повторные короба нет [CLM-002] [CLM-006] [CLM-012].
- Ручное подтверждение зоны остаётся обязательным условием подсказки. Проверенная функция показывает уже подтверждённый код [CLM-005] [CLM-012].
- Печатная этикетка остаётся вариантом для оценки после разбора причин ошибок [CLM-001] [HYP-002] (проверено по CHG-001).

## Польза ↔ затраты и доходы

| Статья | Оценка | Основание | Тип |
|---|---|---|---|
| Ресурс подготовки | Смета учебной недели 36 000 ₽ при потолке 50 000 ₽. Отдельную смету выбранной подготовки и будущих смен надо уточнить. | [CLM-004] | fact |
| Сигналы пилота | +2 п.п. правильной приёмки, обращения у 7% операторов с подсказкой. | [CLM-017] [CLM-018] | interpretation |
| Ожидаемая польза | Гипотеза о снижении ошибок чтения остаётся открытой. | [HYP-002] (пересмотрено по CHG-001). | hypothesis |
| Денежная отдача | Не оценена. Для внутреннего процесса учитываем экономию операций и дополнительные затраты. Цены повторной маркировки на короб и отдельного числа предотвращённых повторов пока нет. | [CLM-004] [CLM-007] | fact о пробеле |

[R4] Для оценки чистой экономии используем число предотвращённых повторных маркировок, умноженное на стоимость одной маркировки, за вычетом дополнительных затрат. Точка безубыточности по предотвращённым повторам равна дополнительным затратам, делённым на стоимость одной маркировки при положительной себестоимости. Для численной оценки нужны раздельный учёт повторной маркировки и замер стоимости материалов и времени. Составная метрика приёмки не даёт этих данных [CLM-004] [CLM-007].

## Риски и условия пересмотра

Поправка активировала два триггера пересмотра. Продвижение подсказки приостановлено. При возврате к варианту заново проверить пороги, смету и допуск, а также результаты сопоставимой проверки этикетки, если она появится [DEC-001] [CLM-003] [CLM-004] [CLM-005] [CLM-017] [CLM-018] (пересмотрено по CHG-001).
