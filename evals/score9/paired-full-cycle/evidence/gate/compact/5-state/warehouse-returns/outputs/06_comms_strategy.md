# Коммуникационная стратегия

## Главное

До повторного C2 экранный текст остаётся материалом для стенда. В момент закрытия короба оператор может сверить код уже подтверждённой зоны на стенде [CLM-012] [DEC-001] (пересмотрено по CHG-001).
Возможность прочитать код в карточке до закрытия подтверждена в стендовом сценарии [CLM-012] [PRM-001].
Использование сообщения в реальных сменах зависит от решения по подсказке и отдельного допуска [CLM-005] [DEC-001] (пересмотрено по CHG-001).

## Аудитория и ситуация

Операторы возвратов на выбранном складе. Момент — перед закрытием первого подходящего короба, когда оператор уже подтвердил зону вручную. В пилоте и на стенде описана именно эта поверхность внутреннего рабочего экрана [CLM-002] [CLM-006] [CLM-012].

## Барьер понимания или выбора

Возможный барьер — оператору трудно сверить код при закрытии короба. Исправленные агрегаты оставляют эту гипотезу открытой. Для текста есть прямое стендовое наблюдение о показе кода [HYP-002] [CLM-012] (пересмотрено по CHG-001).

## Ключевое сообщение и его подтверждение

[R6] Стендовый текст — «После ручного подтверждения зоны вы можете сверить её код на экране перед закрытием короба» [PRM-001]. Проверенная строка интерфейса — «Зона сортировки: {код подтверждённой зоны}» [CLM-012].

## Роль каналов

| Канал | Задача | Почему этот канал | Метрика этапа |
|---|---|---|---|
| Внутренний рабочий экран возвратов | Показать оператору подтверждённый код до закрытия короба. | Код нужен в момент действия, в той же карточке [CLM-012]. | Доля прогонов с ожидаемым отображением отдельно для подтверждённой и неподтверждённой зоны. |

## Чего мы не обещаем

Автоматический выбор зоны, доступность кода без подтверждения, безошибочную сортировку, ускорение работы и переносимость на другие склады. Основание для текста — наблюдавшееся на стенде отображение кода [CLM-005] [CLM-012].
