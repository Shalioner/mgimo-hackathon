# Протокол проверки экрана

Учебный локальный стенд. Проверка от 16 ноября 2026 года. Роль проверяющего — оператор возвратов.

- Сценарий A. В карточке первого подходящего короба оператор вручную подтвердил зону R-12. Перед закрытием экран показал строку «Зона сортировки: R-12». Код совпал с подтверждённой зоной. Оператор мог прочитать его до нажатия «Закрыть короб».
- Сценарий B. Повтор открыли без подтверждённой зоны. Подсказка с кодом не появилась.

Наблюдали видимый код перед закрытием и условие его появления. Скорость, снижение числа ошибок, действия других складов и доступность без подтверждённой зоны этой проверкой не измерялись.
