## Входной контроль эксперимента 1

Для каждого контроля скопирован исходный `projects/family-connect` в отдельную временную папку. В один файл каждой копии дописана строка «Учебная контрольная правка.», затем из распакованного снимка выполнена команда `python tools/c3_approval.py check <копия> --json`.

| Изменённый файл | Статус | Код |
|---|---|---:|
| `outputs/09_run_report.md` | `current` | 0 |
| `outputs/06_comms_strategy.md` | `stale`, указан документ | 1 |
| `sources/f1-family-signal-consent-v2.md` | `stale`, указан источник | 1 |

На исходном кейсе до и после контроля получен `current`. В отдельном модельном прогоне оба режима набрали по 12/12 без критических ошибок. [Результаты сравнения](post-c3/RUN_RESULTS.md).
