# Проверки готовности артефактов (quality gate)

`python tools/decide.py --project projects/<case> --gate projects/<case>/outputs/04_options.md --step 5`

Файл `NN.yaml` подбирается по номеру артефакта. Каждый вопрос — «да/нет» по правилам AGENTS.md §3 и шаблону; `fix` — готовая подсказка, что исправить, если ответ «нет». Код выхода 4 — не готово: исправь только названные пункты и проверь снова, но не больше 2 раз (потом — эскалация по `ledger.py route --failed` или вопрос человеку). Без ответа модели решений проверка не блокирует работу: код 1/3 — проверь по этому списку сам.

Числа и ссылки здесь не проверяются — это делает `tools/verify.py` (кодом, бесплатно).

**Сначала код.** У вопроса может быть `check` — регулярные выражения по тексту артефакта (`all`, `any`, `none`, `min_count`):
- `mode: decide` — ответ полностью даёт код, модель этот вопрос не получает;
- `mode: require` — код проверяет необходимое условие: не выполнено — сразу «нет» без модели, выполнено — модель судит по существу.

Если модель — эмуляция на LLM, она отвечает меткой (`yes / no / unsure`) и дословной цитатой. Уверенность считает код: «да» с цитатой, которая действительно есть в тексте, — 0,95; без подтверждённой цитаты — 0,6 (уйдёт на просмотр).

Несколько артефактов — один вызов: `--gate outputs/04_options.md outputs/05_product_strategy.md …`.

Кодом проверяются только жёсткие элементы шаблона — заголовки разделов (любого уровня) и ID объектов. Формулировки («с чем сравниваем») кодом не ищутся: агент пишет их своими словами, и код дал бы ложное «нет» (проверено на `ryadom`).
