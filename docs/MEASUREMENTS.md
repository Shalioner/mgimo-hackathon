# Что мы измерили

## Главное
Собраны 20 замеров и проверок: сравнение с чатом, пересмотр, стоимость инструментов, возражения и безопасность.
Подтвердились прослеживаемость чисел, продолжение после перерыва и обновление состояния; перевод пересмотра на T2 дал $0,30 при эталоне 6/6.
Не подтвердились экономия всего пересмотра от `revise_lines.py` и достижение порогов в части раундов словаря.
Главный минус: при равной рубрике 10/10 агент стоит $3,24 против $0,11–0,21 у чата; пересмотр на T2 — $0,30 против $0,10.

### Ограничения и расхождения источников

- Baseline и пересмотр — один учебный кейс, малое число прогонов; судья — модель, оценка не полностью слепая. У baseline стоимость агента включает весь процесс с пересмотром, чата — один ответ. Прослеживаемость добавлена после результатов, второе условие — после первого; это отмечено в протоколе.
- Исправления документов, делегирование строк и смена основной модели проверялись после исходного сравнения пересмотра; отдельные протоколы этих доработок заранее не фиксировались. У T2 была лишняя остановка и расхождение баллов с рекомендацией; см. результаты пересмотра.
- Для gate сводка [DESCRIPTION §4](DESCRIPTION.md#4-реализованные-возможности-дополнительного-уровня) даёт ≈165K, а журнал — оценку 150K+ для отдельных вызовов. Обе оценки приведены, точную разницу между ними не считаем. Для `verify.py` измерен размер списка, а не токены повторного живого прогона.
- В замерах хука фразы синтетические, авторы — модели одного семейства. `dev` используется для доработки, `test` — для отложенной проверки; результаты разных раундов нельзя складывать как один непрерывный рост на общей выборке. Модель, effort и взгляд в раунде разных авторов смешаны.
- Во втором этапе хука строгая метрика «открыл навык» введена после прогонов; исходное «навык или trace» не различало контроль. В замере угодливости исходный `test` был просмотрен при поиске причины; свежая выборка служит отдельной проверкой, F06 вынесен за основной подсчёт.
- Для последних раундов в RESULT-файлах решение ещё оставлено человеку; последующие коммиты фиксируют принятие частичного улучшения и остановку: `ec56ba3`, `5ff4dea`. Аналогично раунды хука с непрошедшими порогами сохранены как частичные, хотя доработки вошли в `23b7b6d`.
- В [DESCRIPTION §4](DESCRIPTION.md#4-реализованные-возможности-дополнительного-уровня) тест внедрённых команд назван «4/4»; первичный [отчёт теста](E2E_INJECTION_TEST.md) перечисляет пять ожиданий и итог 5/5 — в таблице использован он. Сравнения с отключённой защитой не было; это проверка одного сценария, не общая гарантия безопасности.

## Что не измерено

Это пробелы в доказательстве пользы, даже если компонент имеет модульные тесты или использовался в E2E ([исходная сводка](DESCRIPTION.md#41-польза-каждого-компонента--сводная-таблица)).

- **SessionStart:** состояние выводится, но контрольного прогона без хука нет; измерили бы время до правильного шага и ошибки выбора проекта с хуком и без него.
- **PostToolUse / validate:** в описанных прогонах не останавливал ошибочную запись; измерили бы пропущенные дефекты и время исправления на одинаковых намеренно ошибочных записях с хуком и без него.
- **MCP:** есть проверка протокола, но в продуктовом прогоне не использовался; сравнили бы одинаковые операции через CLI и MCP по времени, ошибкам и токенам.
- **Субагенты source-extractor / claim-verifier:** участие в E2E не отделяет их эффект от основного процесса; сравнили бы одинаковые материалы с делегированием и без по поддержке утверждений, времени и полной цене. Изоляция `delegate.py` сама по себе этого не доказывает.
- **Пакетное делегирование:** правило следует из накладных расходов вызова, но экономия на полном прогоне не снята; сравнили бы обработку одинакового пакета источников вместе и по одному, включая качество извлечения.
- **Jev / System One:** настоящий провайдер без ключа не проверен, замеры gate относятся к эмуляции на LLM; сравнили бы ответы с эталоном, отказы, задержку и цену обеих реализаций.
- **Типизация фактов и правило о синтетических респондентах:** тестируется соблюдение формата, но частота ошибок без правила неизвестна; сравнили бы смешение фактов и гипотез на одинаковых заданиях с правилом и без.
- **Интервью и модельные респонденты:** в E2E не прогонялись; проверили бы качество исследовательского плана и число проверяемых гипотез, не выдавая синтетические ответы за спрос.
- **models.py и каталог моделей:** обновление версии в живом продуктовом прогоне не происходило; проверили бы время перехода и ошибки маршрутизации при смене доступных моделей.
- **Полный процесс у реальных руководителей:** источники — учебные кейсы, не полевой контроль; сравнили бы время до принятого решения и исправления после новых данных с привычным способом работы.

## Как воспроизвести

Ниже четыре пересчёта сохранённых материалов: baseline, хук на разных авторах и вежливое несогласие последних раундов. Команды запускаются из корня репозитория после установки `requirements.txt` в `.venv`. Они не генерируют новые ответы моделей и не воспроизводят исторические счета или время сессий. Рубрика baseline повторно моделью не оценивается (`--no-judge`).

Каждый пересчёт использует снимок соответствующего коммита: текущий словарь уже другой. Результаты пишутся только во временную папку, исходные JSON не перезаписываются.

```bash
STRATEGIST_PY="$PWD/.venv/bin/python"
replay() (
  set -eu
  set -o pipefail
  snapshot=$(mktemp -d "${TMPDIR:-/tmp}/strategist-measurements.XXXXXX")
  git archive "$1" evals tools projects/ryadom tests/test_hooks.py | tar -x -C "$snapshot"
  shift
  cd "$snapshot"
  "$STRATEGIST_PY" "$@"
)

# Baseline: числа и прослеживаемость сохранённых ответов, без вызова судьи.
replay fbc2bda evals/compare.py --sources projects/ryadom/sources \
  --doc 'чат_материалы=evals/baseline/run1/answer.md' \
  --doc 'чат_поиск=evals/baseline/run2/answer.md' \
  --doc 'агент=projects/ryadom/outputs/03_situation.md,projects/ryadom/outputs/04_options.md,projects/ryadom/outputs/05_product_strategy.md,projects/ryadom/outputs/06_comms_strategy.md,projects/ryadom/outputs/07_validation_plan.md' \
  --ledger 'агент=projects/ryadom' --out recomputed --no-judge

# Хук: отложенная часть раунда разных авторов на словаре этого раунда.
replay ed6ec84 evals/objections/score.py --split test \
  --dir evals/objections/round4 \
  --exclude evals/objections/sets evals/objections/round2/sets evals/objections/round3/sets

# Вежливое несогласие: каждый test на своей замороженной версии словаря.
replay ec56ba3 evals/escalation/polite2/score.py --split test
replay 5ff4dea evals/escalation/polite3/score.py --split test
```

Протоколы и их последовательность проверяются локально через `git show --stat <hash>` и `git log --format='%h %cI %s' -- <путь протокола> <путь результата>`. Для живых restart-теста, пересмотра, угодливости и внедрённых команд требуются отдельные сессии по соответствующим протоколам; их оплачиваемые прогоны эта страница не запускает.
