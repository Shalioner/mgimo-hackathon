## Воспроизводимые команды

В этой машине команды выполнялись через `rtk proxy`; ниже оставлены сами команды. `ASR_PY` — существующий Python с зависимостями, а `VIDEO_FILE` — путь к неизменяемому исходнику.

```sh
VIDEO_FILE='/Users/shalioner/Downloads/Copy this Claude Mod, Never Overpay Claude Again.mp4'
ASR_PY='/Users/shalioner/Downloads/Claude-video-review/.venv/bin/python'
mkdir -p /tmp/mgimo-video-02
ffprobe -v error -show_format -show_streams -of json "$VIDEO_FILE"
shasum -a 256 "$VIDEO_FILE"

ffmpeg -hide_banner -loglevel error -threads 2 -i "$VIDEO_FILE" \
  -vn -ac 1 -ar 16000 -threads 2 /tmp/mgimo-video-02/audio.wav

"$ASR_PY" -m pip install --target /tmp/mgimo-video-02/asr-package \
  --no-deps openai-whisper==20250625

PYTHONPATH=/tmp/mgimo-video-02/asr-package \
OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 \
VECLIB_MAXIMUM_THREADS=2 NUMBA_NUM_THREADS=2 \
"$ASR_PY" -u -m whisper /tmp/mgimo-video-02/audio.wav \
  --model small.en --model_dir /tmp/mgimo-video-02/models \
  --device cpu --threads 2 --language en --task transcribe --fp16 False \
  --beam_size 1 --best_of 1 --temperature 0 \
  --temperature_increment_on_fallback None --condition_on_previous_text False \
  --output_format all --output_dir /tmp/mgimo-video-02/asr \
  > /tmp/mgimo-video-02/asr.log 2>&1

# Точный кадр: T — секунды от начала файла, например 300, 660 или 900.
ffmpeg -hide_banner -loglevel error -ss "$T" -threads 2 -i "$VIDEO_FILE" \
  -frames:v 1 -threads 2 "/tmp/mgimo-video-02/frame-$T.jpg"
```

Просмотрены также восемь обзорных кадров, полученных фильтром `fps=1/120`. Их порядковые номера не использованы как точные таймкоды: релевантные сцены перепроверяются извлечением одного кадра через `-ss`.

Проверочные фрагменты загружались в память из WAV и передавались Whisper как массив, последовательно одним процессом; время каждого результата возвращено к исходному таймкоду прибавлением `start`. Существенная часть проверочного скрипта:

```python
import wave
import numpy as np
import torch
import whisper

torch.set_num_threads(2)
torch.set_num_interop_threads(1)
model = whisper.load_model("base.en", device="cpu",
                           download_root="/tmp/mgimo-video-02/models")
with wave.open("/tmp/mgimo-video-02/audio.wav", "rb") as wav:
    assert wav.getframerate() == 16000 and wav.getnchannels() == 1
    data = np.frombuffer(wav.readframes(wav.getnframes()), np.int16)
audio = data.astype(np.float32) / 32768
clips = [(0, 30), (250, 275), (326, 345), (610, 635), (665, 695),
         (752, 773), (822, 845), (900, len(audio) / 16000),
         (45, 58), (207, 225), (308, 321), (380, 397),
         (716, 730), (865, 874)]
for start, end in clips:
    result = model.transcribe(audio[int(start*16000):int(end*16000)],
        language="en", task="transcribe", fp16=False, temperature=0,
        beam_size=1, best_of=1, condition_on_previous_text=False, verbose=None)
    print(start, end, result["text"])
```

Фактически восемь первых фрагментов и шесть дополнительных выполнены двумя последовательными запусками с теми же параметрами. Отчёты — `/tmp/mgimo-video-02/checks.json` и `checks-extra.json`; содержат тексты, сегменты, параметры потоков и elapsed. При запуске скриптов использовались тот же `PYTHONPATH` и ограничения потоков, что в полном проходе.

- [Anthropic: effort](https://platform.claude.com/docs/en/build-with-claude/effort): проверка смысла параметра, а не подтверждение экономии автора.
