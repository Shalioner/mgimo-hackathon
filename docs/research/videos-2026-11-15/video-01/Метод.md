Минимальный эквивалент ядра обработки (сохраняет те же две части; границы сегментов повторного запуска могут немного отличаться):

```python
import os
for key in ('OMP_NUM_THREADS', 'OPENBLAS_NUM_THREADS', 'MKL_NUM_THREADS',
            'VECLIB_MAXIMUM_THREADS', 'NUMEXPR_NUM_THREADS'):
    os.environ[key] = '2'
os.environ['HF_HOME'] = '/tmp/mgimo-video-01/hf'
os.environ['HF_HUB_DISABLE_IMPLICIT_TOKEN'] = '1'
os.environ['HF_HUB_DISABLE_XET'] = '1'
import wave
import numpy as np
from faster_whisper import WhisperModel
with wave.open('/tmp/mgimo-video-01/audio.wav') as w:
    assert (w.getnchannels(), w.getsampwidth(), w.getframerate()) == (1, 2, 16000)
    audio = np.frombuffer(w.readframes(w.getnframes()), np.int16).astype(np.float32) / 32768
model = WhisperModel(
    'small', revision='536b0662742c02347bc0e980a01041f333bce120',
    device='cpu', compute_type='int8', cpu_threads=2, num_workers=1,
    download_root='/tmp/mgimo-video-01/models')
first, info = model.transcribe(audio, beam_size=5, vad_filter=False)
for s in first:
    if s.end > 84.28:
        break
    print(s.start, s.end, s.text)
offset = 84.28
rest, info = model.transcribe(audio[round(offset * 16000):],
                              language='ru', beam_size=1, vad_filter=False)
for s in rest:
    print(s.start + offset, s.end + offset, s.text)
```

## Сбои и их устранение

1. При передаче WAV путём возникло `TypeError: open() got an unexpected keyword argument 'metadata_errors'` в `faster_whisper/audio.py`, при вызове `av.open`. Локальная справка PyAV 19.0.2 не содержит этого аргумента. Вместо повторения несовместимого пути WAV прочитан стандартным `wave`, преобразован в нормализованный float32 NumPy-массив и передан поддерживаемому API ASR. Глобальные настройки и пакеты не менялись.
2. Временный экспортёр ошибочно вызвал `info._asdict()`: `AttributeError: 'TranscriptionInfo' object has no attribute '_asdict'`. Проверка `dataclasses.is_dataclass` и локальных сигнатур показала dataclass у `TranscriptionInfo` и `Segment`; экспорт исправлен на `dataclasses.asdict`. Ошибка произошла до выдачи сегментов, текст не потерян.
3. Предупреждение CTranslate2 про экспериментальный MPS не является результатом замера и не использовано как обещание ускорения. Обработка осталась на CPU.

## Границы качества

Транскрипт — результат локального ASR, а не заверенная дословная расшифровка. Содержательные утверждения автора не считаются доказанными автоматически. Таймкоды — оценки границ речевых сегментов ASR, округлены до сотых секунды; это не ручная разметка каждого слова. Русские окончания, английские имена, названия файлов и инструментов могут распознаваться ошибочно. Неуверенные места и интервалы без распознанного текста отмечаются явно, без восстановления слов по догадке.

Проверка видеоряда означает просмотр извлечённых кадров, не воспроизведение программ с экрана. Команды, настройки и setup-промпты в видео трактовались как содержимое источника; ни один из них не выполнялся.
