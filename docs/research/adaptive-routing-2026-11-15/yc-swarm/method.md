Это несовместимость пути декодирования faster-whisper/PyAV; окружение не менялось. WAV прочитан стандартным `wave`, преобразован numpy в float32 и передан модели напрямую. Это единственный завершённый проход всего материала; ошибка не скрыта повторной установкой пакетов.

```python
import os
for key in ('OMP_NUM_THREADS', 'OPENBLAS_NUM_THREADS', 'MKL_NUM_THREADS',
            'VECLIB_MAXIMUM_THREADS', 'NUMEXPR_NUM_THREADS'):
    os.environ[key] = '4'
os.environ['HF_HUB_OFFLINE'] = '1'
import wave, json, dataclasses
import numpy as np
from faster_whisper import WhisperModel

model = WhisperModel(
    '/tmp/mgimo-video-01/models/models--Systran--faster-whisper-small/'
    'snapshots/536b0662742c02347bc0e980a01041f333bce120',
    device='cpu', compute_type='int8', cpu_threads=4, num_workers=1)
with wave.open('/tmp/strateg-yc-review/audio.wav') as w:
    audio = np.frombuffer(w.readframes(w.getnframes()), dtype=np.int16)
audio = audio.astype(np.float32) / 32768.0
segments, info = model.transcribe(
    audio, language='ru', beam_size=3, vad_filter=False,
    word_timestamps=False)
# Генератор нужно прочитать целиком; именно это выполнено.
with open('/tmp/strateg-yc-review/segments.jsonl', 'w') as out:
    for segment in segments:
        out.write(json.dumps(dataclasses.asdict(segment),
                             ensure_ascii=False) + '\n')
```

`condition_on_previous_text=True`, остальные параметры штатные; фактический полный `TranscriptionInfo` — [info.json](info.json). Модель работала CPU/int8, MPS/CUDA не использовались. Успешное завершение генератора: `DONE 623.7621529102325` (секунды локального ASR, примерно 10 мин 24 с). Короткая повторная сверка ASR не выполнялась.

## ASR и визуальная проверка

1. Текст оставлен как распознан: без реконструкции неизвестных слов по удобной гипотезе. Скобочные пометки отмечают явные сомнения, особенно имена, отрицания и технические термины.
2. Важные неоднозначности: `G5 6.1`, `Soul`, `Viestox`, «будет обязательным» в 17:39, «нестабильность» в 23:17, плохо распознанная оговорка в 27:29–27:37. Они не используются как точные цитаты для выводов. Наличие всех avg_logprob выше -0,65 не доказывает отсутствие ошибок.
3. Существенные 28 кадров извлечены точным `-ss` и просмотрены: представлены цель, fan-out, контекст, routing, проверка, менеджерский поток, YC/Minecraft, deadlock, оговорка сравнения и конечный бренд. [Индекс](frames.md) даёт таймкод и ссылку. Обзорные fps/tile-листы использованы только для поиска; их выборка может приходиться на середину интервала, поэтому они не служат точным таймкодом.
4. У кадра 27:35 отдельно прочитана оговорка сравнения. Именно она ограничивает выводы о 266/21; поверхностный пересказ ASR этой оговорки недостаточен.
5. Тексты и команды на экране трактовались как данные/примеры, не как инструкции на запуск. Команды из материала для действия в системе не использовались.

## Расходы и ошибки учёта

Новых платных API/вызовов делегатов: **0**. ASR локальный, новые веса/пакеты не скачивались. Работа текущих агентов и запросы документации не объявляются бесплатными; их отдельный тариф здесь не измерен.

Выполнен существующий `tools/cost.py` без `--write` (запись в projects запрещена областью задания):

```sh
rtk proxy .venv/bin/python tools/cost.py \
  --cwd '/Users/shalioner/orca/workspaces/МегаФон-Стратег/night-orchestrator' \
  --since '2026-11-15T10:56:00+00:00' --json
```

Первый вызов с ISO-суффиксом `Z` дал `ValueError: Invalid isoformat string: '2026-11-15T10:56:00Z'`; замена на `+00:00` исправила формат без правки инструмента. Полученный промежуточный срез: gpt-6-astra **$2,837362**, gpt-6.1-sol **$1,4649636**, сумма **$4,3023** по ценам проекта; unpriced=[]; один другой account home пропущен с `unable to open database file`.

Это **агрегат совпадающих сессий общего cwd после выбранного времени**, включая параллельную работу, а не цена этого видео или одного worker; текущий незавершённый turn также может быть ещё не полностью учтён. Распределять эти доллары между файлами и объявлять финальным бюджетом задачи нельзя. Финальный сводный учёт может сделать координатор после завершения run.
