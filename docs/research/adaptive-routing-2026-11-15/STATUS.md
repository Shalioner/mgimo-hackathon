# Адаптивная маршрутизация: состояние интеграции

Среда: codex внутри Orca. Дата: 2026-11-15.

В локальную ветку `research/mgimo-video-2026-11-15` объединены core `4dd6952219da84cba915d78df922794e78506c00` и методика `87edc862e8d75a28ebdad51cd9b53f650408a2b4`. Публикации этой работы на GitHub не было. Это ограниченная первая реализация, не завершённая поддержка всех запрошенных сред.

## Реализовано

- Общая политика host/provider/model/effort/auth/billing, явное включение API, проверка входа и отдельные requested/transmitted/observed.
- Изолированные подписочные текстовые делегаты Codex и Claude Code для явно настроенных отдельных профилей. Реальные аккаунты не подключались; проверки используют fake CLI и HTTP fixtures.
- Отказы и ошибки результата сохраняются в receipt и журнале; malformed JSON и некорректные типы не объявляются успехом. Один запуск обёртки не гарантирует отсутствие внутренних сетевых повторов CLI.
- Единый интегратор реестра, ограниченные независимые задания, разные статусы сдачи и приёмки, адресная проверка исправлений человека. Это методика существующих средств, не новый scheduler.
- Сохранены исследования провайдеров, разбор Home Repo и полный ASR ролика «Агенты Романа» с упоминанием YC. Прежняя транскрипция этого файла не найдена. ASR не является дословной ручной сверкой.

## Открытая работа

Интеграционная проверка координатора: `.venv/bin/python -m pytest -q tests` — **342 passed, 1 skipped**, 34.46 с. Оба CLI `--help` доступны после объединения; `git diff --check` чистый. Пропуск — необязательный openpyxl. Реальные inference-вызовы не выполнялись.

1. Настроить и проверить реальные dedicated профили Codex/Claude: версия, подписка, отсутствие extra usage и влияние managed/cloud конфигурации. Это не подтверждается fake-тестами или одним полем конфигурации.
2. Реализовать и испытать адаптеры ZCode/GLM, DeepSeek Harness, Kimi, Qwen, Gemini CLI, Antigravity и Cursor по [матрице](providers/matrix.md). Сейчас они manual; наличие модели или ключа не включает автоматический запуск. Cursor не считается провайдером Claude; Composer/Grok — предпочтение, не гарантия цены.
3. Проверить реальные исправления метода в новой сессии и сравнить качество/полный расход на одинаковом сценарии. Синтетические примеры в контракте пока задают ожидаемое поведение, не измеренный эффект.
4. Проверить native/Orca transport отдельно: Python gate не контролирует произвольные внешние запуски. Не выдавать receipt одного транспорта за разрешение другого.

Оригинальный Claude Model Selector Pack не получен из-за формы email. Открытый аналог CCR скачан только для чтения; SHA и лицензия в [provenance](providers/upstream.md). Чужие setup/hooks не исполнялись, OAuth gateway не переносился, глобальная память и продуктовые кейсы не менялись.
