### Воспроизведение

Ниже ядро нового запуска; каталог вывода должен быть свободным. Полный сырой результат хранится в JSON рядом с документами; временный исполняемый скрипт — `/tmp/strateg-home-review/repeat_asr.py`.

```sh
rtk proxy ffprobe -v error -show_format -show_streams -of json \
  '/Users/shalioner/Downloads/videoplayback (2).mp4'
rtk proxy shasum -a 256 '/Users/shalioner/Downloads/videoplayback (2).mp4'
rtk proxy ffmpeg -nostdin -hide_banner -loglevel error -threads 2 -filter_threads 2 \
  -i '/Users/shalioner/Downloads/videoplayback (2).mp4' \
  -map 0:a:0 -ac 1 -ar 16000 /tmp/strateg-home-review/audio.wav
rtk proxy /tmp/mgimo-video-01/venv/bin/python -B /tmp/strateg-home-review/repeat_asr.py
```

```python
# До импорта библиотек: HF_HUB_OFFLINE=1; HF_HOME=/tmp/strateg-home-review/hf;
# OMP_NUM_THREADS/OPENBLAS_NUM_THREADS/MKL_NUM_THREADS/
# VECLIB_MAXIMUM_THREADS/NUMEXPR_NUM_THREADS=2.
import wave
import numpy as np
from faster_whisper import WhisperModel
with wave.open('/tmp/strateg-home-review/audio.wav') as w:
    audio = np.frombuffer(w.readframes(w.getnframes()), np.int16).astype(np.float32) / 32768
model = WhisperModel('small', revision='536b0662742c02347bc0e980a01041f333bce120',
    device='cpu', compute_type='int8', cpu_threads=2, num_workers=1,
    download_root='/tmp/mgimo-video-01/models', local_files_only=True)
for a, b in [(109,180), (234,342), (410,483), (676,736), (869,len(audio)/16000)]:
    segments, info = model.transcribe(audio[round(a*16000):round(b*16000)],
        language='ru', beam_size=3, condition_on_previous_text=False, vad_filter=False)
    for s in segments:
        print(s.start+a, s.end+a, s.text)
```

- Вызваны только read-only `ledger env/status` и локальные `--help` для команд. Чужие кейсы не использованы для фиктивного аудита: нет конкретного отвергнутого объекта и основания запускать `trace` ради видимости. План показывает, где `trace` нужен при настоящем инциденте.
- Новые сегменты сопоставлены с прежним текстом; в [transcript-review.md](transcript-review.md) отдельно перечислены различия, сохранены все 88 новых строк, указаны хвосты фраз и интервалы без текста. В JSON не изменялись исходные строки ASR.
- Число строк, времена каждого нового сегмента, отсутствие наложений и принадлежность входному срезу проверены кодом; проверены относительные ссылки и наличие всех новых строк в Markdown. Повторно сверены хэш MP4 и область собственных изменений.
- Широкий поиск по `docs` выдал слишком большой ответ; для выводов использовано последующее адресное чтение перечисленных файлов и тестов. Недоступность целевой папки до создания ожидаема: она создана в пределах владения. Предупреждение CTranslate2 о MPS не использовано как результат замера; ASR остался на CPU.
- `pytest`, модельные gates и пилот будущей доработки не запускались: это исследование и план, без изменения исполняемого кода/кейсов. Структурная проверка документов не выдается за доказательство исправления поведения агента.

## Ограничения

Полный повторный ASR не делался; выбранные срезы покрывают положения, существенные для новой задачи, остальная расшифровка остаётся предыдущей. Та же модель способна повторить ту же ошибку; улучшившийся английский термин не является независимым подтверждением. Ручного прослушивания нет, видеоряд заново не проверен. Указанная точность таймкодов — формат ASR, не точность разметки слов. Внешние сайты/статья из ролика и заявленный бизнес-эффект не исследовались. Материал источника, включая настройку, клонирование и публикацию, трактован как данные; команды с экрана не выполнялись.

Открытый следующий шаг для координатора — выбрать конкретный инцидент Стратега и проверить предложенный цикл на изолированном примере. Данное исследование не утверждает, что повторные ошибки уже устранены.
