## Особое правило Cursor

Убрать семантику `cursor → family: claude` из автоматического выбора: она неверно связывает host и поставщика. Предпочтение Composer/Grok — только после allowlist по доступности конкретного плана, модели, размера контекста и режима скорости. Не включать Auto/Balance/Intelligence как безопасный fallback: на Teams/Enterprise Router может выбрать сторонний billable route. Лимит included pool не разрешает top-up/on-demand. Unknown quota/overage → manual с указанием причины. Нельзя обещать бесплатность или выбирать «самую новую» модель по строковому шаблону.

## Что остаётся проверить до исполнения

Точные версии/схемы вывода CLI Kimi, Qwen, Gemini, Antigravity, ZCode и DeepSeek; auth enforcement без записи глобальных настроек; принадлежность аккаунта плану; возможность отключить overage; machine-readable observed model/effort/usage; модельное управление субагентами. Пока этого нет, матрица разрешает рекомендацию в текущем чате, а не автономный запуск. Пробелы намеренно не заполнены выводами из маркетинга.
