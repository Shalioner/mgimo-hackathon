## Доработка: native документы и уменьшение контекста

Явный native text-only transport проверен на текущем аккаунте Codex 0.169.0.
Инструменты/MCP/skills/hooks отключены для временного потока, постоянные настройки
не менялись. Исходный isolated preflight остаётся manual; это отдельный новый режим.

Короткий прежний запрос с ответом `17`: input **10510** вместо **27126** (-61.25%),
output 5, wall 6.612 с вместо 5.409 с; cached input 2048 вместо 0.
Изменён состав системного контекста, порядок и кэш не контролировались: снижение
контекста наблюдается, ускорение и общая экономия router этим не доказаны.
Receipt: [native-text-only.json](native-text-only.json).

Три синтетических документа обработаны последовательно Luna/low. Карточка о поливе
имеет 0 findings; два оставшихся источника — январь 24%, февраль 18%.
Первый D1 дал T3 с 0.677 при пороге 0.75 и остановил синтез. Добавленная однократная
T1-перепроверка сначала выявила проблему двойного JSON-экранирования цитат; исправлен
формат данных, порог и проверка цитаты сохранены. Старые отказы сохранены в receipts.
После исправления: T1 выбрал **Terra/medium**, Terra сравнила 24% и 18% (-6 п.п.),
T1 quality verdict **accept**. Синтез возобновлён на прежних проверенных карточках;
хэши файлов перепроверены до и после. Это составная проверка, не непрерывный прогон
одного CLI-вызова после финальных правок. Непрерывная цепочка дополнительно покрыта offline tests.

Для контроля тот же запрос и исходные три документа переданы напрямую Terra/medium,
