# Исследования и квитанции проверок

Здесь сохранены исторические эксперименты и исходные результаты, включая неудачные.
Дата в имени — дата опыта, а не гарантия актуальности конфигурации или доступности модели.
`code_snapshot/` и `code/` — исходники соответствующего опыта, не действующий runtime;
рабочая реализация находится в корневом `tools/`. Абсолютные пути в квитанциях описывают
машину автора и не являются переносимыми командами установки.

- `five-agent-d1-2026-11-15/`: прежнее сравнение с D1; часть JSON используется
  регрессионным `tests/test_quality_quote_regression.py`, поэтому сохраняется вместе с ним.
- `four-arm-routing-2026-11-15/`: режимы D1 / D1+Luna / Luna / без обоих классификаторов.
  Отключение Luna относится к роли классификатора, остальные роли сохранены.
- `community-routing-2026-11-15.md` и `community-*.json`: происхождение архитектурных
  приёмов и ограниченные live-пробы выбора инструментов/сокращения истории.
- `d1-quantization-2026-11-15/CANCELLED.md`: отменённое исследование 4-bit, не рекомендация
  устанавливать эту версию и не успешный тест.
- `readiness-review-2026-11-15.md`: исходный аудит с историческими дефектами; его список
  не следует считать перечнем открытых дефектов текущего HEAD.
- `prepush-review-2026-11-16.md`: проверка конкретного HEAD, указанного внутри отчёта.

Механические тесты, модельные оценки, live smoke и пользовательское согласование
различаются. Транспортный успех не доказывает качество классификации; уменьшение байтов
не доказывает экономию токенов; подписочные токены не равны прямым API-расходам.
Не включены веса моделей, личная routing.local.yaml и ключи доступа.
