## Найдено и исправлено

P2: оба вызова `--authorize` из мода передавали model/effort/tier, но теряли
`classifier` из выбранного маршрута. `host_routing.authorize` проверяет отзыв
API opt-in и смену классификатора только при наличии этого поля. Офлайн
воспроизведено: после отзыва opt-in полный маршрут возвращал `needs_review`,
а урезанный — `authorized`.

Теперь поле передаётся для `agent.spawn` и `turn.step`. Два регрессионных теста
падали до исправления и проходят после него. Это закрывает применение устаревшего
маршрута после отзыва разрешения, а не даёт новое разрешение на API.
