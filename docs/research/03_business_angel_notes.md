# Заметки: взгляд бизнес-ангела (из переписки с ChatGPT)

> Сжатый пересказ переписки. Это гипотезы для проверки, а не подтверждённые боли аудитории из ТЗ.

## Главный вопрос
Какая проблема настолько болезненна для конкретного человека, что он хочет её решить, будет пользоваться продуктом и, возможно, платить за него?

## Где искать проблемы: пересечение трёх условий
1. Человек регулярно сталкивается с проблемой.
2. Существующие решения закрывают её не полностью.
3. Решение даёт измеримую пользу: деньги, время, риск, доход.

## Что ценит бизнес-ангел
- регулярность проблемы (привычка);
- проблема стоит денег или часов;
- человек уже пытается её решать (Excel, сервисы, специалисты);
- текущие решения закрывают задачу не целиком;
- результат измерим («2 часа → 10 минут», «−15% расходов»).

## Гипотезы болей (для конечных клиентов)
Информационная перегрузка · потеря времени · финансовая неопределённость · сложность выбора · отсутствие персонализации · недостаток компетенций · страх ошибки · разрозненность сервисов.

## Методика карты проблем
15–20 проблем → частота → стоимость (деньги и время) → как решают сейчас → почему это не работает → оценка глазами ангела → 3 лучшие.

## Как это используется в проекте (решение из docs/PLAN.md, слой 2)
Пользователь агента — product lead «Фабрики продуктов». Взгляд бизнес-ангела — это **skill агента** для оценки болей конечных клиентов того сервиса, о котором принимается решение, а не выбор нашей собственной аудитории. Пять критериев становятся полями `pain.schema.json`.
