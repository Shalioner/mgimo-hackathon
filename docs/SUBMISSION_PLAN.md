## Как читать оценки времени

У каждой задачи две цифры:
- **ИИ** — сколько по часам работает агент (Codex через Orca или Claude Code). Оценки опираются на наши замеры: полный прогон ryadom ≈ 96 мин в Codex, esim-travel ≈ 90 мин в ZCode, шаг 1 ≈ 5–10 мин.
- **Человек** — сколько твоего внимания нужно: ответы на C1–C3, просмотр результата, запись видео. Это узкое место, его и планируем.

Задачи с ИИ-временем можно запускать параллельно в разных воркерах Orca, если они не трогают одни и те же файлы. Пометка **‖** означает, что задачу можно гнать параллельно с соседней.

Команды запускаются из корня репозитория, `PY` = `.venv/bin/python`.
