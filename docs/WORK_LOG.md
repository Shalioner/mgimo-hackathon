## 2026-11-10 (3) — фаза 2: модель данных

- **Гипотеза:** детерминированные валидатор и impact analysis дадут воспроизводимость, которую LLM сам по себе не обеспечивает.

  - `.venv/bin/python -m pytest -q tests` → 19 passed.
