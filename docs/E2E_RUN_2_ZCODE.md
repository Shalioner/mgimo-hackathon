# E2E-прогон 2 — ZCode (GLM-5.3-Flash, Start Plan), кейс «eSIM для путешественников»

- **Среда:** приложение ZCode 0.17.1, провайдер Start Plan, модель GLM-5.3-Flash на всех шагах. Через Orca ZCode не запускается: TUI нет, работает только в приложении. Прогон вёл пользователь, вопросы на остановках пересылались координатору.
- **Ветка:** `Shalioner/e2e-zcode` (`b7cc0f9`), проект перенесён в main: `projects/esim-travel`.
- **Запрос (дословно, одна фраза):** «Думаем запускать eSIM для путешественников — стоит ли и кому продавать?» Новый кейс, не «Рядом»: проверка того, что агент справляется с новыми задачами.

## Ответы человека (координатор от лица руководителя)
- **C1:** «1 — россияне, которые ездят за рубеж. 3 — главное удержать абонентов, роуминг уходит в Airalo и подобные, выручка вторична. Горизонт год, бюджет небольшой. Готовим для доклада руководству. По модели запуска смотри все варианты.»
- **C2:** «Берём ALT-001 с пилотом. Но цены нашего роуминга ты взял из блога Roami — перепроверь по официальному сайту МегаФона, прежде чем на них опираться.»
- **C3:** «Утверждаю. Владелец — я, пилот разбираем через 3 месяца после старта.»

## Результат
- 8/8 шагов, `validate`: 0 ошибок, 0 предупреждений, 40 объектов: 7 SRC (6 открытых + официальная страница megafon.ru), 15 CLM, 5 HYP, 4 ALT (invest, change, status_quo, kill), DEC, 3 PRM, 3 EXP.
- Бриф 458 слов, все документы вместе — около 4872 слов. У «Рядом» в Codex было около 14441.
- Источники: Juniper (рынок travel-eSIM +85% в 2025), пресс-релиз МТС, Билайн, официальная страница МегаФона; блог конкурента Roami и нативная реклама vc.ru — с надёжностью low. Страница Thales упала с 500, агент её честно пропустил.
- **Реакция на поправку человека:** агент сходил на официальный сайт, нашёл 599 ₽/день вместо 399 ₽ из блога конкурента, заменил CLM-009 → CLM-015 **через `supersede`** (старая запись сохранена), перевёл PAIN и ALT на новый источник.
- Обещания (3 PRM) привязаны к функциям и проверяются пилотом EXP-002; в EXP используется новое поле `effort`.
- Верификатор перед C3: claim support **80,6%** (50/62), 12 замечаний исправлены. Запас над порогом минимальный.

## Найдено
1. ❌ **Среда определена как `claude-code`.** ZCode читает CLAUDE.md и ради совместимости выставляет `CLAUDE_SESSION_ID` / `CLAUDE_PROJECT_DIR`. Из-за этого в журнале «рекомендован T1 (Haiku)», хотя в ZCode это GLM-5.3-Flash. **Исправлено:** `ledger.py env` определяет среду по переменным (ZCODE_* раньше CLAUDE*; Claude Code — `CLAUDECODE=1`), session-start хук печатает её, правило в AGENTS §1. Тесты на маскировку.
2. ⚠️ **Верификатор — около 412K токенов** (по отчёту агента: субагент general-purpose на текущей модели) при ~70K на всё остальное. Самое дорогое место прогона. Нужна проверка пачкой или на T1-модели; в ZCode модели субагента не выбрать.
3. ⚠️ Модель одна на все шаги: T3-задачи (варианты, стратегия) выполнены на Flash. Агент честно записал «рекомендован T3, выполнен на GLM-5.3-Flash».
4. Не проверено в этом прогоне: продолжение после перерыва, хуки (ZCode, возможно, читает .claude/settings.json — не подтверждено).
