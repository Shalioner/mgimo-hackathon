# IDEA-001: Одинаковые источники не усиливают основание
- Критерий ТЗ: кр.1
- Цитата ТЗ: «выводы связаны с проверяемыми источниками, факты отделены от гипотез и прогнозов»
- Новизна: ни у кого из описанных в [COMPETITORS](../../COMPETITORS.md) и карточках [Astero81](../research/cards/A-astero81-ai-product-factory.md), [Fighter90 decision skills](../research/cards/A-fighter90-product-decision-skills.md) не описан подсчёт разных файлов-оснований варианта с объединением точных копий. Это ограничение обзора, а не утверждение обо всех продуктах мира.
- Что сделать: один отчёт `tools/evidence_roots.py <project> --decision DEC-NNN --json`: для каждого ALT решения пройти существующие ссылки реестра до SRC и сгруппировать локальные источники по проверенному SHA-256; вывести ID источников, группы копий, число разных файлов и метку `single_root`, когда группа одна. При отсутствии доступного файла или хэша вывести `unknown`, не объявлять разные SRC независимыми. Только чтение, без изменения уверенности и выбора.
- Польза, которую можно измерить: на фикстуре 3 SRC с одинаковыми файлами дают 1 основание вместо видимости трёх; источник без проверяемого файла даёт `unknown`. Сравниваем число SRC из обычного `trace` с `distinct_files` нового отчёта; руководитель видит риск перед выбором варианта.
- ИИ-время: ~45 мин
- Риск: разные файлы тоже могут пересказывать один первоисточник; поэтому результат называется числом разных файлов, а не доказательством независимости, и не меняет ранжирование автоматически.
- Зона правок: `tools/evidence_roots.py`, `tests/test_evidence_roots.py`, новые `tests/fixtures/evidence_roots/**`.
- Черновик приёмки:
  1. `.venv/bin/python tools/evidence_roots.py tests/fixtures/evidence_roots/copies --decision DEC-001 --json` → код 0; у ALT-001 три SRC, `distinct_files: 1`, `single_root: true`; все исходные ID сохранены.
  2. `.venv/bin/python -m pytest -q tests/test_evidence_roots.py -k distinct_and_unknown` → код 0; разные файлы не объединены, недоступный файл даёт `unknown`, цикл ссылок не зацикливает обход.
  3. `.venv/bin/python -m pytest -q tests/test_evidence_roots.py -k read_only` → код 0; хэши всех входных файлов до и после совпадают, сеть и LLM не вызываются.
- Почему не дубль: `trace` показывает происхождение по ID, `impact` — последствия изменения; здесь выявляется точное дублирование файлов за разными SRC при оценке основания ALT. T01–T07 не проверяют число разных оснований; IDEA-002 проверяет оценки, IDEA-003 — очередь, IDEA-004 — исправления, IDEA-005 — перенос. В проверенном `night/integration` прошлых IDEA, вердиктов и веток I пока нет.
- Тест МегаФона: 1 картина → варианты: увидеть вариант на единственном файле до C2 · 2 каждый счётчик раскрывается в SRC и проверенный хэш, неизвестное остаётся неизвестным · 3 локальный скрипт над файлами, без сервиса и установки · 4 фикстура 3 SRC → 1 разный файл, отсутствие записей в проект и вызовов модели.
