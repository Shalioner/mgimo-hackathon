# IDEA-013: Считать собеседников вместо числа цитат
- Критерий ТЗ: кр.2
- Цитата ТЗ: «Готовить вопросы и анализировать интервью; проводить беседы с ИИ-собеседниками в заданной роли для поиска гипотез. Синтетические ответы не выдаются за реальные: они не доказывают спрос и распространённость потребности.»
- Новизна: закрывает наш пробел из [CRITERIA.md](../../CRITERIA.md), кр.2: интервью имеют шаблоны, но не проверены в E2E. Узкое дополнение к правилу `skills/interviews` «3 из 5»: воспроизводимый подсчёт уникальных псевдонимов, а не цитат. Сама возможность интервью уже есть и новой не объявляется.
- Что сделать: один калькулятор `tools/interview_counts.py <project> <coding.json> --json`: для одной явно заданной темы принять строки `respondent,claim,position`, где respondent — псевдоним R01…, position — support|oppose|unclear, claim — активный fact CLM с evidence только из реальных SRC.kind=interview. Тематическое кодирование делает исследователь, не скрипт. Для каждого псевдонима объединить позиции: support+oppose дают mixed, support+unclear остаётся unclear, oppose+unclear остаётся unclear; только одинаковые определённые позиции дают support или oppose. Выдать четыре группы и общий знаменатель уникальных собеседников переданного кодирования, без процентов и без вывода о спросе; scope=coded_respondents_only. Один CLM нельзя приписать двум разным псевдонимам. Истинность псевдонимов и семантику кодирования автоматически не удостоверять.
- Польза, которую можно измерить: на 6 цитатах от 3 собеседников, где R01 дал 3 support, R02 дал support и oppose, R03 дал unclear, результат — support 1, mixed 1, unclear 1, total 3. До — ручной подсчёт рискует превратить четыре положительные цитаты в четыре голоса; после — одна команда сохраняет знаменатель 3 и противоречие R02. Реальные интервью не проводятся в ходе разработки.
- ИИ-время: ~45 мин
- Риск: один человек может быть ошибочно записан под разными псевдонимами; инструмент проверяет только предоставленное кодирование и обозначает `identity_verified: false`, `semantic_coding: not_checked`. Размер удобной выборки не превращается в оценку рынка. Не добавлять имена, контакты и персональные характеристики в фикстуры.
- Зона правок: `tools/interview_counts.py`, `tests/test_interview_counts.py`, новые `tests/fixtures/interview_counts/**`, один абзац о вызове в разделе анализа `skills/interviews/SKILL.md`.
- Черновик приёмки:
  1. `.venv/bin/python tools/interview_counts.py tests/fixtures/interview_counts/project tests/fixtures/interview_counts/coded.json --json` → код 0; total=3, support=1, mixed=1, unclear=1, oppose=0; сохранены все CLM и исходные псевдонимы, процентов нет.
  2. `.venv/bin/python -m pytest -q tests/test_interview_counts.py -k duplicates_and_conflicts` → код 0; повтор той же цитаты не увеличивает число людей, конфликт support/oppose даёт mixed, любая unclear без конфликта даёт unclear; перестановка строк не меняет результат.
  3. `.venv/bin/python -m pytest -q tests/test_interview_counts.py -k synthetic_invalid_and_unknown` → код 0; synthetic_interview, отсутствующий/отозванный CLM, CLM без evidence, один CLM у разных псевдонимов и позиция вне контракта отвергаются кодом 2, синтетика не попадает в знаменатель реальных интервью.
  4. `.venv/bin/python -m pytest -q tests/test_interview_counts.py -k read_only_and_limits` → код 0; источники и реестр неизменны, сеть/LLM не вызываются, identity_verified=false и semantic_coding=not_checked обязательны; полей demand_proven и market_share нет.
- Почему не дубль: IDEA-001 объединяет точные копии файлов по SHA-256; разные цитаты одного собеседника в разных файлах не являются такими копиями. Здесь объединяется явно размеченная единица интервью, а не выводится независимость источников. T05 — сквозной прогон, T04 — общие дефекты таблиц; T01–T07, IDEA-002–010, I-01/I-02 и S-02 не рассчитывают этот знаменатель и смешанные позиции собеседника.
- Тест МегаФона: 1 материалы → картина: руководитель видит, сколько людей стоит за голосом клиента и где есть противоречие · 2 только реальные интервью, CLM сохранены, синтетика/непроверенное кодирование не выдаются за спрос · 3 локальный расчёт по обезличенным файлам, без сервиса интервью · 4 6 цитат → 3 собеседника и 1 явно смешанная позиция вместо четырёх положительных «голосов».
