## Контракт `tools/report.py`

```
python tools/report.py projects/<slug> [--out <путь>]   # по умолчанию projects/<slug>/outputs/report.html
```

- Только стандартная библиотека Python 3.9. Markdown → HTML пишешь сам: заголовки `#…####`, абзацы, списки (`-`, `1.`), таблицы GFM, `**жирный**`, `*курсив*`, `` `код` ``, ссылки `[t](u)`, блоки кода. Неподдержанное — как экранированный текст, но **не терять** содержимое.
- Вход: `outputs/0*.md` по порядку имён, реестр `state/ledger/*.yaml` (читать через функции `tools/ledger.py`, если там есть загрузчик; иначе `yaml` из requirements).
- Выход: **один** HTML-файл. Никаких внешних ресурсов: ни `<script src=`, ни `<link href=http`, ни шрифтов из сети. CSS и JS — внутри файла.
- Структура страницы:
  1. Шапка: название проекта (из `progress.md` или `01_brief.md`), дата генерации, итог стоимости из `state/cost_report.md` (строка `Итого`), если файл есть.
  2. **«Главное» всех документов подряд** — короткий экран для руководителя: из каждого `0N_*.md` блок под заголовком «Главное» (до следующего заголовка того же или более высокого уровня), с подписью документа и ссылкой-якорем на него.
  3. Оглавление по документам.
  4. Документы целиком, каждый в `<section id="doc-0N">`.
- **Каждое вхождение ID** по регулярному выражению `\b(SRC|CLM|HYP|PAIN|ALT|DEC|PRM|EXP|CHG)-[0-9]{3}\b` в тексте документов превращается в
  `<a class="ref" data-id="CLM-001" href="#ref-CLM-001" title="<подсказка>">CLM-001</a>`.
  Подсказка (`title`, экранированная): для CLM — `тип · уверенность · statement · «quote» (SRC-…)`; для SRC — `title · kind · url`; для остальных — `statement` или `title`/`description`, статус. ID, которого нет в реестре, получает `class="ref missing"` и подсказку `нет в реестре`.
- Внизу — **приложение «Реестр»**: по объекту на строку с `id="ref-<ID>"`. Для CLM — полная цитата и источник, для SRC — ссылка, `kind`, `access`, `retrieved`.
- Объекты со `status: superseded | retracted` — визуально зачёркнуты, в подсказке есть статус и `superseded_by`, если поле есть.
- Тёмная и светлая тема по `prefers-color-scheme`. Печать в PDF: `@media print` — без обрезки таблиц (`table { page-break-inside: auto }`, `tr { page-break-inside: avoid }`), ссылки чёрным.
- Ширина экрана телефона: без горизонтальной прокрутки страницы, широкие таблицы прокручиваются внутри своего блока.
- Код возврата: 0 — успех; 2 — нет `outputs/` или реестра (сообщение по-русски в stderr).

## Тесты `tests/test_report.py` (минимум)
1. Генерация на `projects/example` проходит, файл создан.
2. Число `class="ref` в HTML ≥ числу вхождений ID в исходных md (с учётом того, что ID внутри блоков кода тоже считаются — либо не считай их в обоих местах, но одинаково).
3. Несуществующий ID → `ref missing`.
4. В HTML нет `<script src` и `http`-ссылок в `<link`.
5. Экранирование: `<b>` в тексте документа не становится тегом.
6. Таблица GFM превращается в `<table>` с правильным числом строк.
