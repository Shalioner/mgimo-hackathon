# T01. «Чистый клон → запуск» и секреты

**Роль:** реализатор Sol. **Ветка:** `night/T01`. **Приёмка:** `docs/night/accept/T01.sh`.
**Зачем (критерий 3 ТЗ):** «Репозиторий запускается по инструкции… без скрытых настроек». Жюри клонирует репозиторий и выполняет README дословно. Последняя такая проверка была давно, с тех пор добавились MCP, хуки, `decide.py`, `cost.py`.

## Можно менять
- `README.md` — только разделы «Быстрый старт», «Проверка инструментов» и строку `git clone`;
- `requirements.txt` — **только** если без этого не проходит установка (записать причину в отчёт);
- `.env.example`;
- код в `tools/*.py` — **только** чтобы исправить падение, найденное этой проверкой (не рефакторинг).

## Сделать

1. Определи URL `origin` (`git remote get-url origin`) и подставь его в README вместо `<ссылка на репозиторий>`.
2. **Симуляция жюри.** В `/tmp/night-T01/clone` сделай `git clone` **своей ветки из локального репозитория** (`git clone --branch night/T01 "$(git rev-parse --show-toplevel)" /tmp/night-T01/clone`). Там выполни **дословно** команды из README «Быстрый старт» и «Проверка инструментов», по одной, с тем `python3`, который есть в системе. Не используй `.venv` исходного репозитория.
3. Каждое действие, которое понадобилось сверх README (флаг, переменная окружения, ручная установка, `cd`, правка файла), — это дефект. Запиши его в отчёт таблицей «шаг README → что пошло не так → что исправил».
4. Исправь каждый дефект: в README (если это инструкция) или в коде (если падает инструмент). Повтори шаг 2 в **новой** пустой папке (`/tmp/night-T01/clone2`). Повторяй, пока список дефектов не станет пустым (не больше 3 итераций).
5. Проверь MCP-сервер с чистого клона: `printf '%s\n' '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"t","version":"0"}}}' '{"jsonrpc":"2.0","id":2,"method":"tools/list"}' | .venv/bin/python tools/mcp_server.py` — в ответе должен быть список инструментов `strategist_*`. Если это не работает по README, добавь в README одну команду проверки.
6. Секреты: прогони поиск из `accept/T01.sh` по всей истории. Нашёлся реальный ключ — **ничего не чисти**, статус `blocked`, в отчёт: файл, коммит, тип ключа (без самого значения).
7. В README раздел «Требования» должен явно называть: версию Python, что нужна агентная среда (и какие проверены реальным прогоном: Codex, ZCode), что ключей и платных сервисов сверх подписки среды не нужно, что `JEV_API_KEY` необязателен. Если чего-то нет — допиши одной строкой.
