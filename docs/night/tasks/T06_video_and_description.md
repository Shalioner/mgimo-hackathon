# T06. Сценарий видео и доработка описания (без скриншотов)

**Роль:** реализатор Sol. **Ветка:** `night/T06` (от `night/integration` после слияния T03). **Приёмка:** `docs/night/accept/T06.sh`.
**Зачем:** видео до 10 минут обязательно по ТЗ («Что отправить», п. 3), описание — п. 4. Скриншоты и запись делает человек днём. Ночью готовим всё остальное, чтобы днём оставалось только снять.

## Можно менять
- `docs/VIDEO_SCRIPT.md` (новый);
- `docs/DESCRIPTION.md` — разделы §3, §4, §4.1, §7 и ссылки. **Пометки `[СКРИНШОТ]` и `[TODO] Демо-проект МегаФона` не трогать** — их закроет человек после брифа.

## 1. `docs/VIDEO_SCRIPT.md`

Таблица, столбцы ровно: `| Таймкод | Что на экране | Что говорим | Обязательный момент ТЗ / козырь |`.
- Таймкоды в формате `M:SS–M:SS`, подряд, без дыр. Последний конец ≤ `9:30`.
- **Обязательные моменты ТЗ**, каждый ровно с этой меткой в 4-м столбце: `ТЗ: запрос`, `ТЗ: работа агента`, `ТЗ: варианты`, `ТЗ: стратегия`, `ТЗ: продолжение после перерыва`.
- **Козыри** (`docs/COMPETITORS.md` §3), метки: `козырь: три цифры` (первые 30 секунд), `козырь: перенос среды` (продолжение в другой среде: Codex → Claude Code — совмещается с «продолжением после перерыва»), `козырь: возражение руководителя` (self-audit и `trace`), `козырь: report.html`, `козырь: стоимость` (`cost.py`).
- Где операция долгая — строка «ускорено ×N, говорим, что ускорено».
- После таблицы: «Чек-лист перед записью» (шрифт терминала ≥ 16 pt, скрыть `.env` и токены, закрыть лишние вкладки, проверить звук) и «Команды для кадров» — точные команды, которые будут на экране, по порядку.
- Текст «Что говорим» — разговорный, по-русски, ≤ 25 слов на 30 секунд.
