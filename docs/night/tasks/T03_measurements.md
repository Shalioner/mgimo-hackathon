# T03. Страница «Что мы измерили»

**Роль:** реализатор Sol. **Ветка:** `night/T03`. **Приёмка:** `docs/night/accept/T03.sh`.
**Зачем (критерии 2 и 4 ТЗ):** «Оригинальные решения ценятся, если дают **подтверждённую** пользу»; «каждый компонент должен оправдывать свою сложность». У нас есть замеры с протоколом, закоммиченным **до** прогона, — этого нет у конкурентов (`docs/COMPETITORS.md` §3-D). Но они разбросаны по `docs/WORK_LOG.md` и `evals/`. Жюри их не найдёт.

## Можно менять
- `docs/MEASUREMENTS.md` (новый) — единственный файл задачи.

## Сделать

1. Пройди `docs/WORK_LOG.md` (большой: читай по разделам через `grep -n '^## '` и `sed -n`), `evals/*/PROTOCOL.md`, `evals/*/RESULTS.md`, `docs/DESCRIPTION.md` §4.1 и `git log --oneline` (там видно пары «протокол до прогона» → «результат»).
2. Составь `docs/MEASUREMENTS.md`:
   - **«Главное»** (3–5 строк): сколько замеров, что подтвердилось, что нет, главный честный минус (агент дороже чата при равной рубрике).
   - **Таблица замеров**, по строке на замер, столбцы ровно такие:
     `| # | Что проверяли (гипотеза) | Протокол до прогона | Результат | Решение | Файлы |`
     - «Протокол до прогона» — короткий hash коммита протокола (7 символов) или `—`, если протокола заранее не было (так и пиши, это честно).
     - «Результат» — числа как в источнике, «было → стало» где есть.
     - «Решение» — одно из: `принято`, `частично`, `отклонено`, `остановлено` + 3–8 слов почему.
     - «Файлы» — markdown-ссылки на файлы результатов, относительные от `docs/` (`[RESULTS](../evals/baseline/RESULTS.md)`).
   - Обязательно включить (если есть в источниках): baseline «чат vs агент»; пересмотр при новых данных (включая перевод на T2, $0,30); `verify.py` вместо проверки моделью (≈412K токенов → короткий список); gate одним вызовом (≈165K → ≈47K); `delegate.py`; хук возражений (раунды, dev/test); угодливость под нажимом 5/9 → 9/9; вежливое несогласие, раунды 1–3; `dup-main` и необновлённые строки после пересмотра (47 → 0); тест на внедрённые команды 5/5; restart-тест. **Не меньше 10 строк.**
   - **«Что не измерено»** — список компонентов без замера пользы (хуки SessionStart/PostToolUse, MCP, субагенты…), по строке «почему не измерено и чем бы измерили».
   - **«Как воспроизвести»** — команды запуска для 3–4 ключевых замеров, если в evals есть скрипты.
3. **Каждое число** в таблице должно совпадать с источником. Ничего не округляй сильнее источника и ничего не выдумывай. Нет числа — пиши «не зафиксировано».
