# Надзор за ночным прогоном (Claude Code, раз в час)

Надзиратель — сессия Claude Code в основной папке проекта (ветка `main`). Раз в час (`/loop 60m`) снимает снимок, сверяет с сигналами ниже и, если команда ушла не туда, отправляет оркестратору **одну** поправку. Сам код не пишет, ветки не сливает, воркерами напрямую не управляет — только через оркестратора.

## Каждый час

1. `bash docs/night/supervise.sh` — факты и сигналы `⚠`.
2. Выборочно — **одна** вещь глазами, по очереди: последняя слитая карточка → последняя идея и её вердикт → последний отчёт `reports/T0*.md` → `SYNTHESIS.md`. Вопрос один: «это поднимает баллы по ТЗ или уводит в сторону?»
3. Решение по таблице ниже. Нет сигналов и выборка в порядке — поправку не отправлять.
4. Строка в журнал `docs/night/reports/SUPERVISOR_LOG.md` (в основной папке, не коммитить): `HH:MM | сигналы | что посмотрел | поправка: тема или «нет»`.

## Сигналы и поправки

| Сигнал | Что значит | Поправка (тема `НАДЗОР: …`) |
|---|---|---|
| Нет коммитов в `night/integration` > 60 мин | цикл встал: воркер завис, оркестратор ждёт | «Статус: какие воркеры молчат больше 30 мин? Для каждого — send о статусе, через 15 мин без ответа — stop и retry по §3 п. 5» |
| STATUS.md старше 45 мин | оркестратор не ведёт статус | «Обнови STATUS.md по §8 и делай это после каждого слияния» |

| > 60% карточек «нет» | поиск не по теме | «Группа X: фокус на <тема ближе к ТЗ>; убрать из очереди запросы …» |

N: не проходит тест МегаФона, вопрос K — отклонить и не реализовывать» |

| Прошло 6 ч, а новые T/I запускаются | нарушен стоп §5 | «Жёсткий стоп §5: только завершение текущих» |

## Как отправить поправку

```bash
orca orchestration send --to run:<id Run оркестратора: orca orchestration run-list, objective «Ночной прогон…»> --subject "НАДЗОР: <коротко>" --body "<что сделать, по пунктам; ссылка на § ТЗ>"
```

Правила:
- **Одна поправка в час**, конкретная, со ссылкой на пункт ORCHESTRATOR.md. Не переписывать план и не придумывать задачи — только вернуть на рельсы.
- Поправка не может разрешить запрещённое (push, main, удаление, запретные зоны).
- Ответ оркестратора (`reply`) придёт сам; проверить на следующем часе, что поправка выполнена (STATUS.md, «Последняя поправка надзора»).
- Если оркестратор дважды подряд не выполнил поправку — записать в журнал «для человека: оркестратор не управляется» и прекратить поправки (не эскалировать самому).

## Конец ночи
Когда в `night/integration` появился `NIGHT_REPORT.md` и активных воркеров 0 — последний снимок, запись в журнал, остановить `/loop`. Утром человек запускает `bash docs/night/check_all.sh`.
