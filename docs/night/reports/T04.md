## Принятые решения (без человека)
- Разрыв периода отмечается на строке после разрыва; повторы — на всех копиях после первой. Шаг — наиболее частый положительный интервал (при равенстве меньший); двух точек недостаточно для вывода о регулярности.
- Даты одного дня месяца или последних дней месяцев проверяются с календарным месячным шагом. Уникальность периода учитывает все текстовые измерения.
- Числа без суффикса наследуют единицу заголовка. При отсутствии единицы в заголовке ожидается наиболее частая единица; при равенстве — первая встреченная. Проблема указывает строки с отличающимися единицами.
- Min/max сохраняют масштаб исходных чисел, выбросы вычисляются внутри одной единицы методом квартилей inclusive и порогом 3×IQR (от восьми чисел).
- openpyxl не устанавливался: его нет в requirements.txt; отсутствие библиотеки проверяется и сообщает требуемую ошибку с кодом 2. Интеграционный XLSX-тест запускается автоматически, если библиотека уже есть.
- Начальный запуск pytest остановился на не-ASCII bytes-литерале в новом тесте; литерал заменён на явный encode, повторный запуск зелёный.
