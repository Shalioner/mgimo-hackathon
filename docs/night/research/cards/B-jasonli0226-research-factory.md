## Как устроено
README описывает фиксированную последовательность стадий: план, исследователи, детерминированная проверка цитат, синтез, варианты, критика, предложение и оценка.
`verifier/src/quote.ts` нормализует кавычки, дефисы и пробелы, затем ищет точное или ограниченное мягкое совпадение цитаты в тексте источника.
`orchestrator/src/critique-check.ts` проверяет полноту возражений по вариантам, наличие маркеров и то, что цитаты критики встречаются во входных материалах.
`orchestrator/src/eval-check.ts` проверяет наличие оценки по каждому критерию, корректность взвешенного итога и полноту списка обязательных исправлений.
По README оценщик скрыт от автора предложения, а после порога или лимита раундов финальная оценка остаётся за человеком.

## Чем силён (по нашим критериям ТЗ)
- кр.1: перед синтезом цитаты механически сверяются с исходной страницей, а незачёт источников не маскируется как прошедшая проверка — `README.md`, `verifier/src/quote.ts`.
- кр.2: оценка требует балл по каждому критерию и прозрачный пересчёт взвешенного итога; критика должна покрыть каждый вариант — `orchestrator/src/eval-check.ts`, `orchestrator/src/critique-check.ts`.
- кр.3: README связывает генерацию предложения, скрытый rubric и человеческий финальный gate, но этот порядок реализован в отдельном приложении — `README.md`.
