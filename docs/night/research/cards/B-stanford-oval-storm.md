## Как устроено
README описывает двухэтапный процесс: поиск источников и подготовка плана, затем написание текста с цитатами.
Для разнообразия вопросов STORM использует перспективы и имитацию разговора автора с экспертом, основанную на веб-источниках.
Co-STORM добавляет экспертов, модератора, совместный диалог и динамическую карту понятий.
README указывает модульные интерфейсы и возможность отдельно настраивать модели для разных шагов.

## Чем силён (по нашим критериям ТЗ)
- кр.1: разделяет сбор оснований и подготовку текста с цитатами — README.md, раздел “How STORM & Co-STORM works”
- кр.1: задаёт вопросы с нескольких перспектив и отвечает с учётом источников; код требует подкреплять предложения собранной информацией — knowledge_storm/storm_wiki/modules/knowledge_curation.py, классы `AskQuestionWithPersona` и `AnswerQuestion`
- кр.4: Co-STORM позволяет человеку направлять исследование до генерации отчёта — README.md, раздел “Co-STORM”
