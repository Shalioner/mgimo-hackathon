## Как устроено
README описывает анализ голоса профиля и генерацию постов для нескольких социальных платформ. Серверные API-маршруты получают токен IBM из переменной окружения и проксируют запрос к Granite. Страница LinkedIn содержит клиент Supabase и графики метрик вовлечённости. Это развёртываемая веб-программа, не папка-агент.

## Чем силён (по нашим критериям ТЗ)
- кр.1: связка измеряемых метрик вовлечённости с генерацией/анализом контента обозначена как продуктовая аналитика — `src/app/analyze-linkedin/page.tsx`; README описывает аналитику и режимы анализа.
- кр.3: API-ключ передаётся серверным кодом через переменную окружения — `src/app/api/ibm-profile-analysis/route.ts`; это заявленный путь безопасной конфигурации, но приложение также имеет другие настройки.
- кр.4: проверка длины/формата и тона публикаций заявлена в README, разделы «Quality Assurance» и «Content Generation Flow».
