## Как устроено
- Компоненты поддерживаются как Markdown в Claude Code plugin format, затем адаптеры генерируют представления для разных harness.
- Репозиторий описывает CI генерации, валидации и проверки части артефактов установленными CLI.
- Плагин startup-business-analyst содержит навыки анализа рынка, финансов, конкурентов и команды, команды и агента; агент ориентирован на стартапы.
- plugin-eval разделяет статические проверки и экспериментальные LLM/Monte Carlo оценки; README прямо говорит, что модельные оценки не валидированы на человеческих метках.
