## Как устроено
README описывает публикацию и повторное использование skill-packs с происхождением урока.
`backend/mcp.ts` регистрирует инструменты запуска, рефлексии, публикации, поиска, установки и оценки pack; их обработчики вызывают общие API handlers.
`backend/agent.ts` читает установленные packs и добавляет их как инструкцию модели; исход демо при этом задаётся наличием pack, а не независимым оценщиком (`DEMO_FORCE_FALLBACK` также фиксирует warm/cold тексты).
`backend/schema.sql` определяет таблицы skill packs, запусков и установок; README заявляет хранение эпизодов через EverMind.
