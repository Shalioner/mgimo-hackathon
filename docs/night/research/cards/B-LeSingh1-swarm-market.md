## Как устроено
README описывает публикацию и повторное использование переносимых skill-packs с происхождением урока.
MCP сервер предоставляет инструменты для запуска агента, анализа эпизодов, публикации и поиска навыков, установки и оценки.
Рейтинг навыка растёт при подтверждённой установке, завершившейся успешной задачей.
README заявляет реальные вызовы Claude и сохранение эпизодов через EverMind.
