## Как устроено
Корневой skill задаёт порядок исследования, правила обработки источников и формат результата; отдельные справки подключаются по типу запроса.
README и метаданные описывают извлечение свежих сигналов из Reddit, X, YouTube, Hacker News, GitHub и других источников.
Репозиторий содержит MCP-компонент, набор тестов, фикстуры поискового качества и отдельную страницу оценки.
В SKILL.md прописано обращаться с полученными страницами и постами как с недоверенными данными.

## Чем силён (по нашим критериям ТЗ)
- кр.1: инструктивный контракт требует опираться на движок и прикладывать ссылки к утверждениям — skills/last30days/SKILL.md, “Skill contract” и “Output contract”
- кр.1: предусмотрена локальная оценка качества извлечения на фиксированных темах с Jaccard overlap и retention относительно baseline — docs/search-quality-eval.md, описание evaluation step
- кр.1: skill требует отмечать источники с неполным/ошибочным покрытием и не делать выводов об их молчании — skills/last30days/SKILL.md, “Per-run source outcomes”
