## Как устроено
Пользователь вводит имя, тип бизнеса и стиль в Gradio-приложении.
Скрипт последовательно генерирует цветовые предложения, изображения, ищет рыночные сведения и суммирует их, затем пишет соцсети.
В README перечислены требования к ключу Nebius; код обращается к Nebius API через OpenAI SDK.
Отдельные скрытые Gradio-компоненты публикуют функции поиска, генерации изображения и суммаризации как API-инструменты; приложение запускается с `mcp_server=True`.
