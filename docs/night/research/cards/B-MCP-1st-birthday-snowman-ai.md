## Как устроено
README описывает workflow обзора литературы: извлечение ссылок из PDF, поиск публикаций, дедупликация и отбор по критериям включения.
`graph.py` параллельно обрабатывает крупные чанки PDF с ограничением в 4 worker-а и ведёт параллельный каскадный поиск ссылок.
Для каждого найденного результата в коде сохраняются URL, DOI, название, abstract, авторы, год и `found_via`.
`search_services.py` содержит адаптеры к нескольким академическим источникам; `cache.py` отдельно кеширует результаты.

## Чем силён (по нашим критериям ТЗ)
- кр.1: результат снабжён URL, DOI, авторами, годом и указанием источника обнаружения — `graph.py`.
- кр.1: fallback и каскадный поиск по источникам уменьшают зависимость от одного API — `search_services.py`.
- кр.5: поиск ссылок распараллелен с подсчётом статистики по источникам — `graph.py`.
