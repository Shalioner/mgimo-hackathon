## Как устроено
README описывает повторную игру двух LLM-агентов Split or Steal: они общаются, выбирают действие и пишут приватную рефлексию после каждого раунда.
metrics.py строит скользящую корреляцию словесных сигналов с выбором, энтропию действий, окно эксплуатации и составной Deception Index.
distill.py переводит паттерны метрик и событий в карточки защитных навыков, метаданные происхождения связывают карточку с агентами и метриками; prompt_packager.py формирует пакет для ручного выбора.
skill_eval.py оценивает пакет на сценариях fraud_ops/support_cx и выставляет рекомендацию по порогам. Это эвристические проверки структуры, признаков и порога достаточности сигнала, не независимая проверка качества реальных ответов.
README приводит сохранённые JSON результатов и перечисляет веб-демо/сервер; основной артефакт — исследовательская программа.

## Чем силён (по нашим критериям ТЗ)
- кр.1: отделяет наблюдаемые события и метрики от генерируемых защитных навыков и сохраняет ссылки на метрики/события в provenance — shared/skills.py:SkillProvenance, engine/distill.py:_build_skill_card. В README честно перечислены ограничения метрик, одного запуска и отсутствия интервалов неопределённости.
- кр.2: пайплайн связывает поведение агентов, измерения, генерацию навыков и их оценку — engine/metrics.py:compute_all_metrics, engine/distill.py, engine/skill_eval.py:evaluate_bundle.
- кр.4: в README указаны воспроизводимые команды запуска и offline-тестов; авторы также описывают эвристичность индекса и несопоставимость некоторых прогонов — README.md:How it is measured, Limitations.
