## Как устроено
gstack описан как набор ролевых инструментов для продуктового, инженерного, QA и релизного циклов.
README предлагает сценарии office-hours, review, QA и ship.
Инструкции сопровождаются программными утилитами; часть сценариев требует внешней браузерной среды.
В README заявлены 23 инструмента; число указано как заявление проекта.
