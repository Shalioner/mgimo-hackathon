## Как устроено
По README, репозиторий называет себя обладателем главного приза AI Valley Hackathon.
README описывает отдельные роли аналитика рынка, стратега роста, CFO, бренд-менеджера и архитектора персон; координация — конкурентная, с передачей сообщений и общей памятью.
README сообщает, что GPT-4.1 Mini используется для синтеза стратегии/GTM, Gemini Flash — для персон, Claude — выборочно для тона; поиск Exa доступен агентам.
В `backend/market_research.py` поля исследования заданы Pydantic-моделями; несколько подзадач делают веб-поиск и формируют структурированные ответы.
В `backend/models/llms.py` виден OpenRouter-клиент с GPT-4.1 Mini по умолчанию и Exa-клиент.

## Чем силён (по нашим критериям ТЗ)
- кр.3: Разделение рабочих ролей и типов результата в модели исследования облегчает переход от картины рынка к стратегии — `backend/market_research.py`.
- кр.5: Разные модели назначены по типам задач; решение заявлено как результат оценки моделей по задачам — Devpost, раздел Model Strategy; вызовы по умолчанию видны в `backend/models/llms.py`.
