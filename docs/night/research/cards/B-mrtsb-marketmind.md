## Как устроено
На первичной странице Devpost в блоке Submitted to → AI Valley Hackathon указана награда «Winner Best Overall» (строки 151–155).
README описывает отдельные роли аналитика рынка, стратега роста, CFO, бренд-менеджера и архитектора персон; координация — конкурентная, с передачей сообщений и общей памятью.
README сообщает, что GPT-4.1 Mini используется для синтеза стратегии/GTM, Gemini Flash — для персон, Claude — выборочно для тона; поиск Exa доступен агентам.
В `backend/market_research.py` поля исследования заданы Pydantic-моделями; несколько подзадач делают веб-поиск и формируют структурированные ответы.
В `backend/models/llms.py` виден OpenRouter-клиент с GPT-4.1 Mini по умолчанию и Exa-клиент.

## Чем силён (по нашим критериям ТЗ)
- кр.1 «Проработанность»: Структурированные области market research создают каркас картины рынка, но не показывают ссылку каждого вывода на проверяемый источник — `backend/market_research.py`.
- кр.2 «Масштаб использования нейротехнологий»: Devpost описывает отдельные роли и назначение моделей по типам задач; это заявление страницы проекта, а не независимо подтверждённая оценка моделей — Devpost, Model Strategy (строки 102–109); вызовы по умолчанию видны в `backend/models/llms.py`.
