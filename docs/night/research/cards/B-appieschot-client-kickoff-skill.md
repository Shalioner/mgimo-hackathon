## Как устроено
README описывает двухфазный процесс: сначала чтение и извлечение сведений из deck без действий, затем выполнение после подтверждения списка участников.
SKILL задаёт этапы извлечения фактов, разрешения участников через каталог и отдельный блок нерешённых имён.
После подтверждения skill подготавливает встречу, повестку, документ и письмо, показывая все четыре результата для одобрения по пунктам.
Неизвестные сведения оставляются плейсхолдерами; даты и участники не должны выдумываться.

## Чем силён (по нашим критериям ТЗ)
- кр.1: извлечённые люди, даты и задачи должны происходить из deck или каталога, неизвестное явно отмечается — `client-kickoff/SKILL.md`, Guardrails.
- кр.3: явный переход между read-only анализом и действиями после подтверждения — `client-kickoff/SKILL.md`, Phase 1/Phase 2.
- кр.4: готовит четыре выхода в одном пакете с отдельным подтверждением каждого — `README.md`, How it works.
