## Как устроено
- README описывает MCP-сервер, который предоставляет ассистенту спортивные данные Strava и планирование маршрутов с погодой.
- strava_tools.py предоставляет инструменты для активности и тренировочных показателей Strava.
- weather_tools.py добавляет погодный контекст для рекомендаций.
- README перечисляет три API-ключа для подключения и установку Python-пакета; это серверный проект.

## Чем силён (по нашим критериям ТЗ)
- кр.1: сочетает несколько источников в ответе; README описывает планирование пробежки с учётом тренировочных данных, погоды и маршрута.
- кр.1: сообщение организатора описывает цельный сценарий анализа Strava и подготовки рекомендаций по тренировкам, календарю и картам.
