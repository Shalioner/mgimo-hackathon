## Как устроено
README описывает агента диагностики автомобиля, который получает состояние и OBD-II данные через MCP-сервер на адаптере либо через Gradio-симулятор.
`app.py` создаёт LangChain агента с инструментами MCP и локальными инструментами декодирования; в коде задана температура 0 и `InMemorySaver`.
`prompts.py` задаёт правила интерпретации OBD-II, включая обязательное применение расчётного инструмента к PID-значениям.
`tools.py` содержит декодирование VIN, hex и безопасный разбор арифметических формул; README прямо предупреждает, что поиск видео в Space, похоже, не работает.
