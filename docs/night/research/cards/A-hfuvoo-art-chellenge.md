## Как устроено
README верхнего уровня описывает репозиторий как рабочую папку подготовки к хакатону: план, инструкции и навыки для Claude.
Во вложенном `strateg-agent` проект ведёт руководителя продукта через этапы, сохраняет материалы и утверждения, а Python CLI проверяет цитаты, числа, ссылки и структуру решений.
README описывает режим с Yandex AI Studio и запасной режим с моделью среды; секреты задаются через переменные окружения и `.env`.
В `tools/check.py` видны отдельные проверки источников и цитат, чисел, вариантов, стратегии, обещаний, плана проверки, оснований, пробелов и секретов.

## Чем силён (по нашим критериям ТЗ)
