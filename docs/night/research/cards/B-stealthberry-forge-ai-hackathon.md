## Как устроено
Репозиторий содержит starter kit для приёма страхового заявления по голосу.
README описывает поток Voice AI → извлечение JSON → webhook → n8n → Airtable.
Workflow создаёт запись обращения в Airtable и возвращает подтверждение.
Setup guide предлагает облачный или локальный запуск n8n и указывает шаги импорта данных и workflow.
