## Как устроено
Devpost связывает заявку с корневым GitHub-репозиторием и отображает отметку Winner в спонсорской категории GenAI Genesis 2026.
README описывает чат-агента исследования мутаций на LangGraph: поиск данных, пять специализированных персон, judge, проверка качества с повторным поиском и итог с цитатами/ограничениями.
Репозиторий включает FastMCP-интерфейс к публичному NCBI Datasets API и отдельную службу Primer3; опубликован LangFlow workflow JSON.
По дереву GitHub на проверяемой ветке `main` доступны только `config.py` и `main.py` из `backend/app`; код графа LangGraph, узлы и состояние, описанные README, отсутствуют. Заявленная реализация agentic research по исходникам не подтверждается.
`agentic_genome_primer_platform.md` прямо называет себя описанием предлагаемой платформы; заявленные в нём времена и качества — не измерения.

## Чем силён (по нашим критериям ТЗ)
- кр.1: README описывает разделение этапов поиска, гипотез, судьи и проверки качества; это описание, не доступная для проверки реализация — `README.md`.
- кр.2: README заявляет финальный ответ с цитатами и ограничениями; доступный `backend/app/main.py` передаёт запрос графу, но графа в публичной ветке нет.
- кр.5: MCP-сервер документирует инструменты и ресурсы NCBI Datasets для IDE — `backend/unofficial_ncbi_mcp/README.md`; это взаимодействие с внешним MCP-сервисом в составе полноценной программы.
