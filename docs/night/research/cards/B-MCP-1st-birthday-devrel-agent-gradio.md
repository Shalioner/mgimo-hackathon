## Как устроено
README описывает анализ публичного GitHub-репозитория и выпуск шести вариантов DevRel-контента.
`app.py` собирает интерфейс Gradio, получает метаданные, коммиты, их diff и изменения README из GitHub.
`services.py` содержит адаптер к Anthropic и структурированные типы `RepoProfile` и `ContentVariant`.
README заявляет контроль качества и оценивание, но в проверенном файле `services.py` поле score лишь хранится; работающий оценщик не подтверждён.

## Чем силён (по нашим критериям ТЗ)
- кр.1: анализирует репозиторий и недавние изменения для контекста текста — `app.py`, `services.py`.
- кр.3: перед генерацией собирает фактические метаданные, коммиты и diff; но в проверенных файлах не подтверждена проверка каждого обещания — `app.py`.
