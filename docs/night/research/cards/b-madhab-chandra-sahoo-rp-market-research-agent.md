## Как устроено
README описывает граф с супервизором, планировщиком, гибридным поиском, исследователем, критиком и автором результата.
Узлы графа держат решения маршрутизации; состояние передаётся частично, а трасса фиксирует агента и длительность.
Проверка цитат извлекает маркеры, а детерминированная проверка сверяет числовые утверждения с найденными фрагментами.
README указывает цикл grade → rewrite → retry → escalate и ограниченную одной попыткой правку критиком.
Для оценки заявлены golden-набор с вопросами вне корпуса и ложными предпосылками, пороги метрик и автономный запуск офлайн.

## Чем силён (по нашим критериям ТЗ)
- кр.1: числовые утверждения и маркеры цитат сопоставляются с контекстом, а ложные срабатывания критика отделяются — `src/market_research_agent/rag/citations.py`.
- кр.1: README заявляет тесты на вопросы вне корпуса и ложные предпосылки, где система должна честно отказаться от неподтверждённого ответа — `README.md`, разделы “Try these” и “Evaluation”.
- кр.5: в README явно описаны переключатели, отключающие дорогие этапы, и измерения времени/стоимости для локального запуска; цифры являются заявлениями README — `README.md`, “Performance and cost”.
