## Как устроено
README описывает двухфазное выявление аномалий кошельков: сигналы по сохранённым данным, затем обогащение верхних результатов данными Polymarket API и повторное ранжирование.
В `fraud_detection.py` признаки и веса собираются в числовой score; отдельный Isolation Forest даёт ещё один anomaly score.
Endpoint расследования в `api/fraud.py` вызывает набор функций для истории сделок, совпадающих рынков, тайминга и разбора выигрышных сделок.
`railtracks_agent.py` передаёт этим функциям структуру инструментов; в доступном фрагменте отчётность синтезируется через watsonx, а не через оркестрацию Railtracks.
README помечает AI-пояснение отключённым по умолчанию. Это сервис анализа рынков и кошельков с UI и backend, не папка агента.
