## Как устроено
README описывает DeerFlow 2.0 как harness с ведущим агентом, субагентами, памятью, инструментами и sandbox.
Архитектура разделяет publishable harness и приложение Gateway с API и пользовательским интерфейсом.
Руководство по субагентам описывает ограничения инструментов, бюджеты и передачу независимого исследования параллельным исполнителям.
README заявляет обязательную конфигурацию, запуск Docker или локальных сервисов и веб-интерфейс.

## Чем силён (по нашим критериям ТЗ)
- кр.1: субагенты возвращают структурированные результаты, которые ведущий агент проверяет и синтезирует; отдельная граница фиксирует цитируемые выдержки — docs/guide/subagents.md, описание отчётов субагентов и knowledge-source snapshots
- кр.4: долгие результаты сохраняются для чтения и проверки после завершения или перезапуска — docs/guide/subagents.md, раздел про результаты batch и evidence snapshots
