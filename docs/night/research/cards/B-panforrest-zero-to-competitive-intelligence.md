## Как устроено
API получает описание стартапа и просит Gemini через Google Search найти 4–6 конкурентов.
Ответ проверяется Zod-схемой с полями конкурентов, SWOT, отличий, рекомендаций и позиционирования.
При ошибках перебираются четыре модели Gemini; при rate limit предусмотрены повторы.
Отдельный чат отвечает на вопросы, используя переданный ему контекст анализа.
Схема результата не содержит ссылок на источники, цитат или меток «факт / гипотеза / прогноз».
