## Как устроено
- Поток вопроса может рекурсивно разбиваться на подзадачи, отвечать на них и сводить ответы с ключевыми точками и источниками (`docs/llm_flow.md`).
- Task orchestration описывает типизированные обработчики, которые порождают дочерние задачи через Redis Streams (`src/map_filter_reduce_llm/task_orchestration/README.md`).
- В документации по конкуренции предлагается выполнять долгие LLM-вызовы без блокировки, а блокировать только короткое обновление состояния (`docs/llm_locking_strategy.md`).
- Страница проекта описывает мониторинг графа задач отдельными агентами и использование Tavily; это заявление участника, не проверка работы.
