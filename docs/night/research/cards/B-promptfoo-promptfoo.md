## Как устроено
В примере YAML задаёт пять независимых измерений ответа поддержки: корректность, решение вопроса, честность, уместность передачи человеку и соответствие языку; каждой метрике задан порог. CSV связывает сообщения с контекстом, ответами и severity. README описывает отдельный CLI для запуска оценок, но запуск проекта не выполнялся.
