## Как устроено (3–6 строк, только то, что видно в файлах)
По README контракт поступает через email-trigger, текст PDF извлекается, а оркестратор Copilot Studio передаёт работу четырём специалистам. Инструкции требуют получить из Dataverse активные правила, оценить каждый пункт и сохранить результаты, после чего сформировать отчёт. Схема хранит контракты, правила, результаты и отчёты в отдельных таблицах. Официальный пост Microsoft называет VendorGuard самым высоко оценённым проектом конкурса и описывает оценки по 15 правилам в пяти измерениях.

## Чем силён (по нашим критериям ТЗ)
- кр.1: разбивает сложную проверку на измерения и явные правила, результаты Red/Amber/Green сохраняются — `docs/dataverse-schema.md`, `docs/agent-instructions.md`.
- кр.2: оркестратор делегирует специализированным агентам; актуальный справочник правил читается из хранилища — `docs/agent-instructions.md`.
- кр.3: представлены схема данных, инструкции агентов и описание автоматизации; README заявляет 15 проверок, но код/экспорт решения в репозитории не представлен — README.md.
- кр.4: по README авторов, процесс сокращает проверку с 2–4 часов до менее 2 минут; это заявление проекта, независимых замеров нет — README.md.
