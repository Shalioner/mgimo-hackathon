# Жюри: запуск, демонстрация и проверка «Стратега»

**Подготовлено 16 ноября 2026.** Здесь — короткий вход в поставку.
Открытые ошибки и задания разработчику: [TEAM_HANDOFF_MEGAFON.md](TEAM_HANDOFF_MEGAFON.md).
Инструкция локальной decision-модели: [D1_MACOS.md](D1_MACOS.md).

## Что проверять

«Стратег» помогает пройти от продуктового запроса до решения с проверяемыми
основаниями. В реестре связаны источник, утверждение, гипотеза, вариант, решение
и обещание. При новых данных можно увидеть, что именно нужно пересмотреть.
Человек подтверждает бриф, выбор варианта и итоговый пакет.

Дополнительный слой — маршрутизация моделей. Локальная D1 классифицирует
подзадачу; исполнение выполняет разрешённая модель агентной среды. Это не
означает, что весь продукт работает офлайн: локальны D1 и проверки кодом,
а облачный исполнитель/веб-поиск зависят от выбранного host и его аккаунта.

## 1. Самый короткий путь: посмотреть продукт без загрузки D1

Распакуйте выданную командой папку репозитория и откройте терминал в её корне.
Для воспроизводимости пакет должен содержать коммит `e626b5a` с реализацией,
`af4316e` с передачей проблем и этот гайд. Эти коммиты создавались локально;
наличие их в публичной ветке GitHub нужно проверить перед раздачей ссылки.
Не считать старую default-ветку автоматически актуальной поставкой.

Нужен Python 3.9+; на машине разработки базовое окружение использовало 3.9.6.
Команды ниже для macOS/Linux; Windows-команды — в [README](../README.md).

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python tools/ledger.py status
.venv/bin/python tools/ledger.py validate projects/example
.venv/bin/python tools/ledger.py impact projects/example CHG-001
```

Ожидается: список кейсов; для учебного example **0 ошибок и 2 предупреждения**;
затем цепочка затронутых оснований и решений по CHG-001. Предупреждения относятся
к незавершённому пересмотру учебного кейса и не скрыты как «всё зелёное».
`impact` показывает влияние, сам не выбирает новый вариант и не переписывает кейс.
Эти команды не вызывают D1 или платного исполнителя. Установка зависимостей
использует сеть; дальнейшая эта демонстрация выполняется кодом.

Для просмотра стратегии можно открыть `projects/esim-travel/outputs/report.html`
в браузере. Конкретная версия отчёта зависит от выданного commit: обновления
рабочего каталога не следует незаметно смешивать с закоммиченной поставкой.

Затем откройте папку в поддерживаемой агентной среде и напишите:

> Помоги оценить запуск eSIM для путешественников. Начни с постановки задачи,
> отделяй факты от предположений и остановись на подтверждении брифа.

Это уже модельная работа в вашем аккаунте. Без D1 базовый workflow доступен,
но выбранный недоступный D1 не будет скрыто заменён API: состояние будет указано
как недоступное/требующее проверки, а ручная работа не выдаётся за автороутинг.

## 2. Проверить именно локальную D1 на Mac

Этот путь проверен на **macOS + Apple Silicon**. На Intel Mac/Windows/Linux
данный MLX-сервис не подтверждён. Нужен установленный Python 3.12 arm64.
Загрузка весов многогигабайтная: время зависит от сети, поэтому установка D1
не входит в обещание «пять минут». На уже настроенном Mac можно сразу перейти
к `status` и пробному запросу.

Перед установкой ознакомьтесь с разделом лицензии в [D1_MACOS.md](D1_MACOS.md).
Для коммерческого корпоративного внедрения у LFM Open License есть ограничение
по выручке; демонстрация не означает автоматически полученного права внедрения.

На новом Mac, где ещё нет MLX-окружения:

```sh
python3.12 -m venv ~/.cache/strategist/d1-2b-lab/mlx-venv
~/.cache/strategist/d1-2b-lab/mlx-venv/bin/python -m pip install -r requirements-local-decision-mlx.txt
~/.cache/strategist/d1-2b-lab/mlx-venv/bin/python tools/local_decision_mlx.py download
.venv/bin/python tools/d1_control.py start
.venv/bin/python tools/d1_control.py status
```

Не переустанавливайте существующее окружение поверх работающего без проверки.
Downloader использует закреплённую revision и SHA256, включая калибровку.
Проверенный вариант — `LiquidAI/d1-2B-MLX-8bit`; ниже 8-bit для этой поставки
пока не рекомендуем, качество на них не проверено. Веса не входят в Git.

В **новом** `knowledge/routing.local.yaml` достаточно следующего блока для
пробной классификации. Если файл уже есть, объедините настройки, не затирайте его:

```yaml
automatic_routing:
  classifier: local-d1
  local_d1:
    mode: service
    reuse: false
```

```sh
.venv/bin/python tools/route_request.py --prompt-file docs/examples/jury-routing-request.md --host codex --classify-only --execute
```

`--classify-only` обязателен для этого smoke: исполнитель не запускается.
Проверяйте успешность транспорта, ответы/вероятности и фактическую модель.
`needs_review` означает, что ответ не принят автоматически, а не успешный выбор.
Статус процесса `running` сам по себе не доказывает готовность модели.
Проверка этого примера на машине разработки дала `status: classified`,
`classification.status: accepted`, T1 / normal / text. `result.status: not_started`
ожидаем: исполнитель специально не запускался. Рекомендация `manual` из-за
отсутствующего subscription profile не отменяет успешную локальную классификацию.
Вероятности зависят от конфигурации вопросов; точные числа не являются критерием установки.
После демонстрации:

```sh
.venv/bin/python tools/d1_control.py stop
```

`start` устанавливает пользовательский LaunchAgent с автозапуском при входе.
`stop` останавливает сервис, но не удаляет plist. Модель также автоматически
выгружается после простоя; её холодная загрузка отличается от тёплого запроса.

## 3. Локально или глобально — что поддерживается

| Область | Как работает сейчас |
|---|---|
| Один кейс внутри `projects/` | Использует инструменты и настройки своей установки Стратега |
| Несколько копий Стратега у одного пользователя Mac | Могут разделять один D1-сервис и веса; hooks/config у каждой копии свои |
| «Глобально для пользователя» | LaunchAgent и приватный сокет D1 доступны независимо от открытого кейса; это не системная служба для всех пользователей |
| Все произвольные репозитории автоматически | Не реализовано; одного глобального D1 недостаточно для автороутинга |
| Другой компьютер | Отдельная установка runtime/весов и настройка host; доступы не переносятся автоматически |

Не переносите/удаляйте checkout, из которого установлен LaunchAgent: он хранит
абсолютный путь к сервису. Не запускайте второй установщик поверх первого из
другой копии. Полная инструкция совместного использования — в D1_MACOS.md.

## 4. Подключение автоматического выбора модели к host

Проверка D1 выше не включает hooks и не подтверждает право запуска модели.
Установить hooks/mod в текущую копию можно отдельно:

```sh
.venv/bin/python tools/install_host_routing.py
.venv/bin/python tools/install_host_routing.py --apply
.venv/bin/python tools/doctor.py doctor --host claude-code
# Для Codex-приложения вместо claude-code укажите codex-app.
```

Нужен блок `automatic_routing.host_routing` из
[примера конфигурации](../knowledge/routing.local.example.yaml): включённая среда,
allowlist реально доступных моделей, таймаут. Не копируйте чужие имена моделей
или согласие на T4 без проверки своего аккаунта. Пример — шаблон, не включённый
по умолчанию доступ. После установки открыть новую сессию host.

| Интеграция | Граница подтверждения |
|---|---|
| Локальная D1 + Python-router | Живые классификации подтверждены |
| Claude Code mods | Код/регистрация и Node contract-тесты подтверждены; живой native runtime пока не закрыт |
| Codex | Есть отдельные адаптеры; обычный UserPromptSubmit не переключает основную модель. Возможности конкретного приложения надо проверять |
| Cursor/Copilot/Windsurf и прочие | Наличие AGENTS.md не доказывает автоматический выбор модели; не заявляем проверенное покрытие |

Для жюри пока не обещаем полностью готовый Claude autorouting:
[MF-02 и MF-05](TEAM_HANDOFF_MEGAFON.md). Не отключайте корпоративную защиту ради демо.

## 5. На чём и как тестировали

Окружение разработки подтверждено 16.11.2026: MacBook Air M1 (`MacBookAir10,1`),
8 GiB unified memory, macOS 15.7.9 (24G830). Основной Python 3.9.6; изолированный
MLX Python 3.12.13; MLX 0.32.4, MLX-VLM 0.7.11. Модель — pinned MLX 8-bit,
revision указана в `tools/local_decision_mlx.py`. Это одна машина, не испытание
всех устройств; расход RAM зависит от остальных приложений.

| Проверка | Что измерено | Где доказательства |
|---|---|---|
| Качество роутинга | 20 разных синтетических кейсов; 17 совпадений tier+effort, 8 уверенных решений, 0 ошибок среди принятых | [Quality](research/d1-routing-quality-2026-11-15/README.md) |
| Повторы/кэш | Группа пяти одинаковых запросов: 9,00 → 1,66 с, 5 → 1 вычисление | [Reuse](research/d1-reuse-2026-11-16/README.md) |
| Разные задачи, cache off | Те же 20 задач в двух вариантах, 40 запросов; 3 → 2 native-вопроса: median worker 2,15 → 1,76 с; все choices совпали | [Overhead](research/d1-overhead-2026-11-16/README.md) |
| Доставка/отмена | Реальные UNIX sockets с тестовым worker, свои UUID, таймауты, отмена; это не проверка качества LLM | `tests/test_d1_service*.py`, `test_d1_reply_isolation.py` |
| Переносимость | Экспорт подготовленного commit без личного routing.local.yaml; обнаруженная зависимость тестов от личного конфига исправлена | `docs/WORK_LOG.md`, `tests/test_codex_routing_hook.py` |
| Claude mod | 12 Node contract-тестов; native test блокировался launcher/sandbox | [README мода](../plugins/strategist-routing/README.md) |

Холодный запрос в последнем эксперименте: около 14,76 с, из них загрузка около
12,49 с. Кэш ускоряет повторы, не произвольные разные задачи. Цифры не являются
общей точностью на рынке, гарантированным p95, экономией денег или итоговым ROI.
Локальные эксперименты D1 не запускали облачных исполнителей. Все raw receipts,
условия и ограничения лежат по ссылкам; не смешивайте эти замеры со стоимостью
полного продуктового прогона в другой среде.

## 6. Что проверить перед выдачей жюри

- Выдать архив/ветку с указанными коммитами и этим документом; записать SHA выдачи.
- Проверить команды в отдельной папке, без личных конфигов и секретов автора.
- Проверить наличие сети для pip/Hugging Face либо заранее подготовить законно
  распространяемые артефакты. Не обещать полностью автономную установку.
- Разделить короткое демо реестра и опциональную загрузку D1: жюри не должно
  ждать веса, чтобы увидеть смысл продукта.
- На выбранном компьютере выполнить smoke и показать фактический результат.
- Указать открытые ограничения, прежде всего Claude runtime и лицензию.

Установка на совершенно чистом втором компьютере ещё не подтверждена.
Описанная проверка переноса использовала существующий Python environment
разработчика; её нельзя выдавать за чистую установку всех зависимостей с нуля.
