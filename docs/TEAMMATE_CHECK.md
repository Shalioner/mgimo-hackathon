# Сокоманднику: что проверить перед полной сдачей

Обновлено 16 ноября 2026. Ветка: `research/mgimo-video-2026-11-15`.
Реализация и результаты: [отчёт приёмки](research/prepush-fixes-2026-11-16.md).
Это рабочая версия для проверки, не заявление о полной production-готовности.

## 1. Чистая установка на своей машине — открыто

Создай новый checkout без .venv и личной конфигурации автора:

```bash
git clone --branch research/mgimo-video-2026-11-15 https://github.com/Shalioner/mgimo-hackathon.git strategist-review
cd strategist-review
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pytest -q tests
node --test plugins/strategist-routing/tests/routing.node.mjs
.venv/bin/python tools/ledger.py validate projects/example
.venv/bin/python tools/doctor.py doctor --host claude-code
```

Node нужен отдельно для тестов мода. Для другого хоста укажи его в doctor.
Локальная MLX-модель требует macOS Apple Silicon и отдельной установки из
[README](../README.md); общие Python-тесты не устанавливают веса.

**Приёмка:** установка проходит без путей/файлов автора, тесты не падают;
каждый skip и предупреждение doctor объяснены. У автора полный набор проверялся
на чистом Git-экспорте, но с существующим окружением зависимостей, поэтому именно
установка с нуля пока не подтверждена.

## 2. Живой Claude-мод и Haiku — открыто

Прочитай [native routing](NATIVE_HOST_ROUTING.md),
[каскад](CLASSIFIER_CASCADE.md) и [условия доступности Claude](CLAUDE_ELIGIBILITY.md).
Используй свой допустимый аккаунт и профиль, не копируй авторские credentials.

1. Посмотри план `.venv/bin/python tools/install_host_routing.py`.
2. Примени установку в своём checkout через `--apply`, если план корректен;
   затем выполни doctor и открой новую сессию Claude Code.
3. Проверь загрузку `plugins/strategist-routing` самим Claude runtime.
4. На простом synthetic запросе сохрани выбранные и реально переданные model/effort.
   Проверь следующий запрос другой сложности и возврат к его исходному уровню.
5. После настройки собственного dedicated subscription profile проверь fallback
   на Haiku/low при контролируемой недоступности API и локального классификатора.
6. Проверь отказ при отзыве разрешения и отсутствие исполнения инструмента при
   неуверенном/некорректном ответе. Не повышай T4/max без отдельного согласия.

**Приёмка:** есть завершённый живой ход и квитанции применения маршрута,
не только установленный файл/успех unit tests. Отдельно укажи, если хост не возвращает
независимый observed model. Сейчас Node-контракты проходят, живой Claude/Haiku не доказан.
Не обходи требования региона, авторизации или доверия hooks.

## 3. API и локальная память — условия эксплуатации

- Тестовый ключ автора истекает **17 ноября 2026** и не входит в Git. Настрой свой
  ключ и точный grant по [OpenRouter](OPENROUTER_DECISION.md). Наличие ключа само
  по себе не разрешает отправку данных; для проверки используй synthetic запросы.
- На MacBook Air M1 8 GiB локальная модель заработала после освобождения памяти:
  холодный запуск около 13 с, отдельный тёплый запрос 1,34 с. При critical pressure
  guard останавливает загрузку. Это штатный отказ, guard отключать не нужно.
- Проверь холодный/тёплый запуск и переход на следующий разрешённый классификатор
  по [D1_SERVICE](D1_SERVICE.md). Сохрани ошибки наряду с успехами.
- Каскад инструментов подключён к явным library/CLI входам. Глобального перехвата
  всех инструментов Orca/Codex нет. Подписочные confidence — условные оценки,
  не калиброванные вероятности. Подробности: [TOOL_ROUTING](TOOL_ROUTING.md).
