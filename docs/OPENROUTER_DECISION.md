# Decision-модель через OpenRouter

Проверено 16 ноября 2026 в Codex на MacBook Air M1, 8 GiB, macOS 15.7.9.
Модель: `perplexity/pplx-decider-v1.3:free`. Это отдельная проверка API-классификатора:
исполнители задач, Luna и платные резервные модели не запускались.

## Быстрый проверочный запуск

Создайте отдельный ключ OpenRouter с **лимитом $0**, без сброса лимита, с ограниченным
сроком действия. В этом прогоне выбран один день. Сохраните его вне репозитория
в файл с правами `600` либо передайте через `OPENROUTER_API_KEY`. Не вставляйте ключ
в чат, командную строку, Git или отчёт.

```bash
.venv/bin/python tools/openrouter_decision_smoke.py \
  --execute \
  --key-file "$HOME/.config/strategist/secrets/openrouter-test-key.txt" \
  --output /tmp/strategist-openrouter-smoke.json
```

Имя отчёта должно быть новым. Без `--execute` сеть не вызывается. Скрипт проверяет
лимит ключа через `GET /api/v1/key`, затем отправляет один синтетический запрос с
вопросами `noul`, `choice`, `score`. Он не меняет `routing.local.yaml` или глобальные
настройки. При ошибке нет повторного запроса, смены модели или исполнителя.

## Что исправлено

- OpenRouter использует `/api/alpha/decisions`, прежнее безусловное добавление
  `/systemone` было несовместимо с этим API.
- `openrouter` — шлюз; поле ответа `provider: Perplexity` обозначает исполнителя.
  Эти идентификаторы теперь проверяются раздельно.
- Каталог OpenRouter сопоставляет запрошенный `:free` с canonical ID
  `perplexity/pplx-decider-v1.3-20261112`. Разрешено только это точное соответствие;
  другая версия не принимается автоматически. Запрошенный и полученный ID остаются
  разными полями в квитанции.
- Проверяются типы вопросов, диапазоны, наборы вариантов, распределения и наличие
  идентификаторов. Отказ не считается успешным функциональным smoke.
- Запрос фиксирует `provider.only: [perplexity]`, `allow_fallbacks: false`.
  Нулевой бюджет разрешён только для указанного точного free-маршрута и подтверждённого
  внешнего лимита $0. Общий API-адаптер доверяет подтверждению оператора;
  smoke дополнительно проверяет лимит по API. Ненулевой или отсутствующий `usage.cost`
  не проходит проверку результата. Сам по себе локальный бюджет не устанавливает лимит на сервере.

Настройки провайдера приведены в `knowledge/routing.local.example.yaml`.
Для других моделей нужны отдельные protocol/model/provider/grant и проверка совместимости.

## Результаты и ограничения

Первый реальный ответ пришёл за 0,549 с, но был правильно помещён в карантин из-за
неизвестного canonical ID. После проверки каталога и исправления сопоставления
повторные ответы прошли. Финальный smoke: **0,620 с, 135 входных и 3 выходных токена,
стоимость $0** по `usage` ответа. Это время HTTP-вызова, без предварительной проверки
ключа; не чистое время вычисления модели и не оценка p95.

Дополнительно через `route_request.classify_request` отправлены пять различных
синтетических случаев из `evals/routing/d1_quality_cases.json`: Q01, Q06, Q11, Q16, Q20.
Все пять прошли транспорт и проверку идентичности. Q01/Q06/Q20 приняты, Q11/Q16
получили `needs_review` при существующем пороге 0,75. Порог не подстраивался.
Это smoke интеграции, а не доказательство качества маршрутизации или превосходства над D1.

Исходные квитанции: [research/openrouter-decider-2026-11-16](research/openrouter-decider-2026-11-16).
`smoke.json` сохраняет первоначальную ошибку; `smoke-final.json` — финальную проверку;
`routing-smoke.json` — пять запросов через роутер. Секретов в отчётах нет. После всех вызовов `/api/v1/key` подтвердил общую
стоимость ключа $0 (`key-cap-after.json`).

Регрессионные проверки: 133 теста в `test_decide.py`, `test_route_request.py`,
`test_routing_policy.py`, `test_openrouter_decision_smoke.py`. Независимое ревью
выявило ложный успех smoke и потерю пакета при частичном отказе; оба случая
исправлены и покрыты тестами. Корректный `refusal` сохраняется для проверки T1,
но не считается успешным функциональным smoke.

**Native-автороутинг обновлён:** по явному запросу включён каскад API → локальная
 decision-модель → подписочный T1/low. Подробности и границы Claude —
[CLASSIFIER_CASCADE.md](CLASSIFIER_CASCADE.md). Ключ действует один день и не входит
в поставку для жюри; на другом компьютере нужен собственный ключ.
